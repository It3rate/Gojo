# Pattern layers, field correspondence and deliberate passes

This exploratory checkpoint adds a bounded analysis path above the numeric
kernel. The source graphs retain phase routing, contribution identity,
sampling, field labels, local finite laws, selected focus and history. Numeric
carriers occur only in the explicit presentation interpretations.

Run:

```powershell
dotnet run --project experiments/QualitativeFrieze -c Release -- --layers
```

The outputs are the [interactive gallery](../../experiments/QualitativeFrieze/results/layers/gallery.html),
[standalone figure](../../experiments/QualitativeFrieze/results/layers/gallery.svg),
[diagnostic projection](../../experiments/QualitativeFrieze/results/layers/diagnostics.json)
and [preview](../../experiments/QualitativeFrieze/results/layers/gallery-preview.png).
The JSON is a derived report, not a restorable native graph.

## Questions and structural choices

The experiment separates these questions:

| Read | Connected evidence | What it does not establish |
| --- | --- | --- |
| Which drive contributed? | Actual phase receipt, output-law read, move and axis | A shape label or a unique cause inferred from a picture |
| Which path was committed? | Sampling route, event occurrence, ordered applications, delta and position reads | An unsampled continuous physical trajectory |
| Where is the field quiet? | Selected occupied role, actual support witnesses, explicit neighborhood and ordinal clearance shells | Calibrated distance, Euclidean medial axis or a universal aesthetic objective |
| Where do layers meet? | More than one distinct contributing label witness in the same actual cell | Independent evidence, material duplication or geometric retracing |
| What did an edit do? | Source and tool fields, selected finite law, focus, carried complement, local applications and timeline | Automatic optimization or a material transfer law |
| Does a motif appear in the other role? | Focused template, role correspondence, actual candidate cell maps and induced directed adjacency | A unique reconstruction of clocks, order or stroke history |

Both field roles remain occupied participants. Choosing one role as the source
of a clearance read makes the question asymmetric; it does not make the other
role nonexistent. Reversing that focus asks a different useful question.

## Rhythms, contributions and sampling

The combined-drive fixture connects a root recurrence to a rightward component
and an alternating vertical component. Grouped sampling combines both actual
emissions into a diagonal displacement. Sampling each component firing
commits them separately and produces a staircase with the same terminal
displacement. Neither result needs a native diagonal operation or a zigzag
classifier.
The root read groups a bounded FIFO cascade. This is simultaneity at the
selected sampling resolution, rather than a proof of physical simultaneity;
the component event order remains in the trace.

A slower variant has two actual root phases. Both trigger horizontal motion;
only one triggers the vertical recurrence. This is a relation-defined event
schedule, without a global time variable or a host modulo clock. Phase counts
do not establish equal elapsed durations.

`FriezeDriveAnalysis` publishes:

```text
analysis = (fixture-surface -> trace) -> (sample-reads -> unresolved)
sample-read = ((trace -> actual-sample) -> actual-sampling-route) ->
              ((actual-applications -> axis-contributions) ->
               ((actual-delta-read -> actual-position-read) -> unresolved))
axis-contribution = (actual-axis -> actual-applications) -> displacement-read
```

The reader checks membership, event order, native output rows and commit
boundaries against the supplied trace. Unknown emission remains open input on
the axis reads. A cancellation in net displacement does not erase its actual
applications. Two separate traces can also be observed in their explicitly
shared frame; their events and histories stay distinct.

## Quiet focus and multiple support

The authored nested field supplies actual cells, ordered columns and rows,
two roles and shared uncalibrated pitches. Its original directed topology is
retained. Clearance selects a separate observation neighborhood containing
the actual edges and explicitly supplied reverse edges. The observer therefore
does not silently replace direction with a metric.

The ordinal shell chain records predecessor relations rather than source
distances. Connected local maximum plateaus remain whole; the experiment
selects plateaus at the last reached shell. Here all 64 white cells are one
shell from dark participation, so all tie. The naive rule of filling every
quiet candidate erases the pattern. Its all-dark counterexample stays in the
gallery and native pass history.

A subsequent proposal selects one actual row/column landmark within that
plateau. The landmark is authored, not inferred to be a unique center. A tool
field labels its actual cell with the selected role and every other cell with
its explicit partner. An ordinary union law applies the addition. This shows
that clearance can supply a candidate set without choosing an aesthetic
action. A finer neighborhood, additional features or explicit preferences may
distinguish candidates; this coarse read cannot invent that information.

A second experiment reuses the same motif one step along the actual column
cycle. Every shifted label retains its original label and correspondence row.
Union publishes a final two-role field, while a separate support read keeps
both contributing labels. A subtraction pass then removes the selected
multiply-supported cells. The remaining cells carry their old labels and the
previous pass stays in the timeline. These passes are observational structural
transformations; they neither drain material nor alter the source field.

The pass law is connected finite participation:

```text
(source-label -> tool-label) -> finite-law-read -> result-label
```

Union, intersection and difference use the same mechanism with different
visible rows. Unknown labels, conflicting support, an incomplete law, open
focus or incompatible cell basis leave obligations. No missing cell is
implicitly assigned the background role.

## Reusable motif and field correspondence

`MotifFieldCorrespondence` selects an actual subset of a template field and
tests supplied candidate maps into another field. The same reader accepts a
same-role correspondence or an opposite-role correspondence; the ordered
role-map rows supply the distinction. It checks induced directed adjacency in
both directions, not just equal role counts or matching labels at isolated
cells. Unselected cells, labels, internal edges and cut edges remain explicit
on both sides.

The gallery uses half of the nested field as a reusable motif. Identity
recognizes it in place; the actual half-shift recognizes it in the opposite
role; a one-column correspondence recognizes it in the separately shifted
layer. Supplied wrong maps retain mismatches. A bounded set of column-order
reflections asks a stronger question and retains failures rather than treating
visual resemblance as a mirror proof.

A motif and its complete field can encode the same final visible assignment
under a declared scope and correspondence. They carry different useful access
paths and can have very different representation costs. The field alone does
not uniquely determine the process: stroke order, repeated passes, pauses,
independent drives and sampling can disappear in a union. Recognition therefore
keeps multiple candidates and makes no inverse-history promise. Display colour
inversion, role exchange, relation reversal, geometric reflection and Gojo dual
are separate operations.

## Results and verification

The recorded run uses twelve root drives per fixture:

| Fixture | Actual motion applications | Committed samples | Selected-view endpoint |
| --- | ---: | ---: | --- |
| Grouped alternating drives | 24 | 12 | (48, 0) |
| The same drives, component sampling | 24 | 24 | (48, 0) |
| Slower vertical recurrence | 18 | 12 | (48, 0) |

The tests also establish equality of the first two fixtures' endpoints after
each root drive, rather than only at the final coordinate. The overlay uses
one actual measured calibration for both independent cursors. Those numbers
belong to the selected view; the source analysis has no numeric locations.

The field has 128 actual cells. Its retained pass results are:

| Field | Dark / light cells | Total role regions | Selected half-shift exchanges roles? |
| --- | --- | ---: | --- |
| Original nested field | 64 / 64 | 2 | Yes |
| Fill all quiet candidates | 128 / 0 | 1 | No; 128 role mismatches |
| Add one explicit landmark | 65 / 63 | 3 | No; 2 role mismatches |
| Shifted contributing layer | 64 / 64 | 2 | Yes |
| Union of both layers | 96 / 32 | 9 | No; 64 role mismatches |
| Subtract 32 multiply-supported cells | 64 / 64 | 6 | No; 128 role mismatches |

The last row restores equal counts but changes connectivity and loses the
original half-shift role exchange. Better balance under one read therefore
does not establish preservation of another property. The one-cell addition
already breaks that symmetry. These are exact counterexamples under the
declared field domain and maps, with their mismatches retained.

The 64-cell template has three expected successful correspondences: identity
in the original field, half-shift into the opposite role, and one-column shift
into the donor field. Wrong identity/half-shift role pairings fail. All sixteen
supplied opposite-role column-reflection candidates fail for this nested
template; the nearest two in label count each have eight mismatches. That
does not rule out other maps or a different template/domain. A focused unit
case separately proves opposite-role recognition through an explicitly
reversed chain.

All retained native sources and analyses contain **zero carriers and zero
numeric locations**. The complete experiment retains 184,225 native element
identities, including timelines and all offered matching certificates; the
field branch accounts for 164,997. This is an inspectable proof fixture, not
a compact codec. Source-program reuse, a minimal final-field representation
and fully retained history are different storage contracts.

Verification adds 49 focused cases: 7 drive analysis, 15 motif correspondence,
16 field passes and 11 field analysis. It tests positive reads, wrong topology,
open inputs, incomplete focus, duplicate routes, missing laws, forged or
omitted evidence, stale history and causal accounting. The generated gallery
and its preview were visually inspected. `dotnet test Gojo.slnx -c Release
--no-restore --verbosity minimal` passes **3,134 tests across twelve test
projects**, including 704 qualitative execution cases. No kernel change was
needed for this checkpoint.

## Next useful experiments

The next training task can choose among a small explicit set of edits and
compare several retained reads: legality, quiet plateaus, multiple support,
desired correspondences and complexity. This checkpoint supplies those
mechanics, with authored choices. A preference can improve one perspective
while making another worse; no scalar reward currently establishes their
tradeoff.

Open work includes economical motif extraction from observations, candidate
generation beyond supplied finite maps, continuation-aware contour reasoning,
curved or fractional ribbon suppliers, adaptive rhythm coupling, and learned
selection of edits. The rectilinear ribbon supplier still leaves diagonal ink
unresolved; plotting a diagonal path does not complete that field supplier.
The explicit cell fields also cost more than the compact driving programs.
This checkpoint makes no computation-speed or memory-compression claim.
An edited field does not yet supply an inferred stroke program or guarantee
the original path's retracing/crossing constraints. Those need a separate
continuation or field-to-path read before feeding the result back into a
drawing controller.
