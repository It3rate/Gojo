Circle construction

Begin with a point. Select an offset through its outward possibility. Attach a radius, establish a return, and divide the circumference. Landmarks come from this construction; no X/Y grid is needed.

Look at the actual syntax

Selected lines from the native construction fixture. The caller binds the common reach to the radius, then selects the circle, partition or landmark reader.

let $origin = point(carrier(), 0);
let $outward = orthogonal($origin);
let $contour = crystal($outward);
let $offset_pattern = $outward -> (?reach -> $contour);
let $ray = crystal(orthogonal($origin -> $origin));
let $radial_start = point($ray, 0);
let $radial_end = point($ray, 1);
let $radius = $radial_start -> $radial_end;
let $start = point($contour, 0);
let $radial = group($origin -> $radial_start, $radius, $radial_end -> $start);
root bind(?reach, $radius);
let $end = point($contour, 1);
let $whole = $start -> $end;
let $closure = $end -> $start;
let $circle_pattern = group($offset_pattern, $radial, $whole, $closure);
let $fourths = carrier(subdivision(unit_of($contour), 4));
let $four = group($circle_pattern, span($fourths, 0, 4) -> $whole);
root group($four, point($fourths, 1));

What happened to “anchor = origin → centre”?

In the earlier example, let $anchor = $origin -> $centre; created a relation from the original point to its supplied X/Y representation, then gave that relation a local name. It was neither an alias for the point nor a pre-existing circumference marker. That later example now calls it $centre_representation. This construction has one source point and needs no such coordinate representation.
