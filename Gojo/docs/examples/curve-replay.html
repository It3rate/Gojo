What happens to the old answer?

Imagine shaping a curved handle in a drawing tool. Four controls define its curve. We have calculated one point at parameter t = ½. Now we raise the first inner control.

What “stale” means here: the earlier answer still describes the earlier curve. It cannot yet serve as a current answer after a premise changes. This is different from a wrong calculation.

This walkthrough illustrates the verified bezier-replay.gojo fixture. The buttons select recorded stages; they do not run the Gojo kernel in the browser. Coordinates use local drawing units. The parameter midpoint is not necessarily halfway along the curve’s length.
