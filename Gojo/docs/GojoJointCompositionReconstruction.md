# Reconstructing shape from anonymous joint streams

Exploratory composition study above the kernel, 22 October 2026. The question
is whether local joints, qualitative position and separate symmetry evidence
can support a newly constructed shape after the original edge pairings and
position words have been withheld. This is an authored reconstruction
mechanism, not a newly trained model or an extension of the kernel's axioms.

[Inspect the three attempts](../../experiments/QualitativeFrieze/results/joint-reconstruction/gallery.html)
or open the [whole source sheet](../../experiments/QualitativeFrieze/results/joint-reconstruction/overview.html).
The [recorded measurements](../../experiments/QualitativeFrieze/results/joint-reconstruction/summary.json)
retain per-case outcomes and message ablations.

## What is being connected

The preceding [learning pilot](GojoOrnamentLearningPilot.md) retains native
boundary routes and recurring fragments. Whole-route recall cannot compose a
strictly unseen arrangement. This study instead constructs candidate edges
from a description of participating roles and their relations. It supplies a
possible proposal-and-critique mechanism for later learning; it does not train
that mechanism or automatically update the earlier learned dictionary.

```text
independently executed teacher program
  -> exposed current native geometry
  -> joint / order / symmetry / area-context analysis
  -> fresh anonymous message, with explicit discarded detail
  -> standalone native transport and exact message read
  -> local ray-pairing proposal and sampled ordinal gaps
  -> new native graph, optional assumed closure
  -> message-only structural critic
  -> next proposal with retained previous feedback
  -> selection among three attempts

teacher correspondence -> separate assessment after selection
```

The source programs are prepared before decomposition. Sixteen cases include
closed polygons, a concave outline, inward and outward returns, distributed
points, disconnected translated/reflected copies, four turned polygon lobes,
and actual T/four-way physical joins. A damaged enclosure retains its missing
passage. Two cases re-execute the earlier L00016 and L00064 teacher units at
their original curriculum descriptors. Shape names are presentation labels;
they are not receiver instructions or classification answers.

## The native message

`JointShapeDescription.Message.Surface` connects the following information:

```text
((motion frame -> selected geometry basis) -> joint roles)
  -> ((local joint reads -> (horizontal buckets -> vertical buckets))
    -> ((symmetry clauses -> component role scopes)
      -> (closure goal -> (interior contexts -> open obligations))))
```

Each role and local ray has a fresh identity. The receiver is given local
direction scopes and witnessed opposed/perpendicular ray pairs. It is not
given the identity of the original stroke, its opposite endpoint, its length,
its uncalibrated reach or its execution cause. Ray slots therefore need to be
paired again during construction.

A complete native opposed-pair inventory also excludes an unadvertised
straight continuation. This keeps a known corner from silently flattening.
When that inventory is open it supplies positive pairs only. Perpendicular
evidence remains a supported subset: zero proven right-angle pairs does not
assert that every pair is non-perpendicular.

The two ordered bucket streams retain before/after and equal-projection
relations on each selected axis. They omit the original motion words and
spacing. Equal projection does not merge sites: several independent roles can
share a horizontal or vertical bucket. A receiver can choose a different gap
size while preserving a valid coarse ordering.

Component scopes retain which roles belong together mechanically. They do not
specify a path through those roles or supply an inventory of filled faces.
These are useful, substantial clues; the experiment does not claim to rebuild
everything from a handful of letters alone.

Joint labels such as corner, continuation, T and four-way joint are local
display reads over actual ray participation. They are not primitive tags in
the native packet. Endpoint displacement supports a direction/tangent read
only where the source offers the actual straight passage. An unsupported
tangent or incomplete inventory remains an obligation.

### Interior context is separate from perpendicularity

Two rays can be perpendicular at either a convex corner or a reflex corner.
The interior distinction needs the selected area's ordered incoming/outgoing
context. The message therefore retains turn refinements attached to anonymous
boundary contexts, separately from its local ray-angle evidence.

The critic requires a coherent candidate boundary context for these
refinements. Finding one locally suitable corner somewhere is insufficient.
An outline with the expected connections can still fail this contextual read.
Unknown within-quadrant direction changes remain open rather than being
silently treated as straight or as a particular angle.

### Symmetry remains another stream

`JointSymmetryEvidence` examines the public native graph through explicit
direction substitutions, shared-reach cancellation and proposed translations.
Its analysis retains actual site/stroke correspondences and unmatched, missing
and unresolved participation. It does not inspect pixels or private recipes.

The receiver packet crystallizes a smaller version: direction actions,
anonymous role correspondences, explicit exceptions and open geometry
obligations. Original translation words and edge maps stay in the analysis
audit. One candidate action must fit one consistent translation across its
advertised scope, including disconnected components. Independently sliding
each component does not satisfy the same rigid-action claim.

An exception referring to a known joint retains that anonymous joint role,
so its qualitative location can be read from the order stream. Passage-only
exceptions remain anonymous obligations. The packet does not supply a hidden
ideal outline, missing coordinates or a pairing for each missing passage.

Right-angle and two/four-fold rotation reads require the explicit native
quarter-turn interpretation. Independent axes alone do not establish those
angles. The current action vocabulary does not discover arbitrary equal
angular subdivisions. Partial symmetry can coexist with an asymmetric defect;
a bounded unsuccessful search is not evidence that no symmetry exists.

## Three construction attempts and defaults

The receiver creates fresh sites for the advertised roles. Complete ordinal
orders support a sampled position word using a shared uncalibrated gap.
Opposed local ray slots can then propose an edge when the advertised heading
and role order are compatible. This uses native direction/order reads, not
numerical coordinate fitting or an image-comparison score.

The three authored policies are:

1. Local pairing with equal ordinal gaps.
2. Shorter ordinal spans, wider horizontal gaps and discouraged previously
   violated pairings.
3. Symmetry-aware pairing with balanced gaps and retained feedback. If a
   previous native joint witness reports a flattened corner, try a symmetric
   default with wider outer gaps on both axes.

Ordinal span is participation in the published bucket sequence, not measured
distance. The sampling schedule and penalty weights are experiment-level
heuristics. They are not an innate kernel algebra, a general optimizer or a
learned repair policy.

A closed-area goal can propose one bridge for a component with two exposed
ends and sufficient existing participation. The added stroke has its own
assumption scope and witness. It is dashed amber in the gallery and remains
an open assumption in assessment. The original open observation is retained;
the decoder does not retroactively claim that a missing stroke was observed.
Branching networks and insufficient evidence can remain open.

The critic compares each new graph with the message: ray directions and
pair relations, ordinal order, component membership, closure, supported
crossing/overlap checks, action correspondences and coherent interior
refinements. Supported, violated and open claims have separate native
witnesses. Its authored quality score weights supported/violated claims;
open claims remain visible. This is not a probability or a proof that the
highest-scoring candidate is the uniquely intended concept.

Selection uses that message-only assessment, then assumption and unresolved
participation counts for ties. The independent teacher edge comparison is
performed afterward. It does not choose the winning attempt. Later policies
receive previous feedback, but a changed policy or a changed drawing alone
does not establish useful feedback adaptation.

## Information boundary and retained evidence

The experiment serializes each message as native structure and imports it
into an independent frame before reconstruction. Original teacher sites,
edge pairings, absolute position words, reach identities and factory history
are outside the receiver packet. The transport reader validates the declared
message shape and its aliases rather than recovering fields from private
ancestry.

Three archives deliberately preserve different contracts:

| File | Retained information |
| --- | --- |
| `messages.gojo.json.gz` | Standalone anonymous native messages |
| `receiver-episodes.gojo.json.gz` | Imported messages, main and ablated attempts, assumptions and assessment witnesses |
| `audit.gojo.json.gz` | Teacher analysis, source-to-role correspondence, transport and selected candidate correspondence |

The audit is private to the decoding contract, not encrypted or unavailable
to a human reviewing the repository. It must not become an input to a
receiver advertised as operating only on anonymous messages. The JSON
gallery is a presentation of these reads, not their native source of meaning.
Numeric coordinates exist only in the separate SVG adapter.

## Recorded results and qualifications

The captured run has 16 independent sources, 48 main attempts and another
144 attempts across three message ablations. Fourteen selected attempts
recover exactly the teacher's unordered edge inventory under the retained
role correspondence. The other two retain every observed edge and add one
explicit assumed closing bridge each.

Edge-inventory agreement is narrower than geometric or conceptual identity.
Aspect ratio, exact reach words, flow history and unrequested detail can
differ. A more square-looking reconstruction of an originally rectangular
source may remain valid at the communicated resolution; absent symmetry
evidence is not a negative instruction forbidding that interpretation.

Fifteen selections have no proven violation under the current critic. Open
claims remain. J16, the re-executed L00064 case, preserves all 14 observed
edges but fails three coherent interior-context claims. That is a retained
failure, rather than a successful full reconstruction or merely an unknown
answer.

J07's equal-gap proposal flattens the four-point contour into a diamond with
intermediate straight sites. Its complete opposed-pair inventory rejects four
such new continuations. The third attempt reacts to that witness and widens
the outer gaps, restoring the bends without teacher coordinates. It is selected
over the initial proposal. This demonstrates one useful authored feedback
repair, not a learned policy or general repair rate.

The other fifteen selections use attempt one. One source changes pairings in
a later attempt without improving the selected result. This is still a small
controlled test of reconstruction and criticism, rather than training evidence.

Removing symmetry or interior-turn streams mostly preserves the easy edge
pairings in these fixtures while changing what can be assessed. Removing
both axis-order streams produces no constructed strokes in this backend;
the missing embedding stays open. This is a limitation of the current
proposal mechanism, not a theorem that joint or symmetry information can
never support construction without those orders.

The native messages contain 21,208 participants across the cases, compared
with 5,118 in the corresponding raw graph/binding packets: about 4.14 times
as many. The extra structure exposes useful interpretation and checks, but
this round does not demonstrate compression. Participant counts are also
different from serialized byte size or runtime cost.

The native quarter-turn correspondence catches incompatible stretching of
an otherwise matching construction. General diagonal crossings, finer
within-quadrant angle distinctions, curved-path tangent inference and full
figure/ground mechanics remain outside the demonstrated scope. Symmetry
currently concerns visible undirected passages, not equivalence of the
generating flow or complete wallpaper-group classification.

Ray priority uses the advertised vertical bucket, horizontal bucket and
heading before assigning pairing indices, rather than borrowing teacher
path/site/ray enumeration. Truly indistinguishable coincident roles and
same-heading slots can still leave ties. A focused test reverses source sites,
strokes, joint rows and ray rows and checks recovered edges through the source
identity map. Another withholds global hints from three oblique strands and
admits different provisional pairings. Broader permutation coverage and larger
independently encoded cases are still needed beyond these controls.

Verification passed the solution-wide run (4,957 tests at that checkpoint)
and the final 42 focused composition tests. The gallery checker inspected all
16 cases, 48 displayed attempts, 144 ablation attempts, 64 SVGs and three native
archives, with 21 desktop/mobile browser states and no browser errors.

## Reproduce and inspect

Run from the repository root:

```powershell
dotnet run --project experiments/QualitativeFrieze -c Release -- --joint-reconstruction
node experiments/QualitativeFrieze/tools/check-joint-reconstruction.cjs
```

Use a new destination to preserve the captured record, or select a smaller
case set:

```powershell
dotnet run --project experiments/QualitativeFrieze -c Release -- --joint-reconstruction --source J05,J08,J12,J16 --output artifacts/joint-reconstruction-recheck
node experiments/QualitativeFrieze/tools/check-joint-reconstruction.cjs artifacts/joint-reconstruction-recheck/gallery.html
```

The sources are in
[`JointReconstructionSources.cs`](../../experiments/QualitativeFrieze/Composition/JointReconstructionSources.cs),
the exposed contract in
[`JointShapeDescription.cs`](../../experiments/QualitativeFrieze/Composition/JointShapeDescription.cs),
action reads in
[`JointSymmetryEvidence.cs`](../../experiments/QualitativeFrieze/Composition/JointSymmetryEvidence.cs),
and proposals/criticism in
[`JointShapeReconstruction.cs`](../../experiments/QualitativeFrieze/Composition/JointShapeReconstruction.cs).
The runner retains the main results, ablations and native archives together.

The next useful experiment is to create ambiguous messages whose alternatives
require different pairings, test explicit ordering permutations and train
proposal/query/edit selection on held-out outcomes. Compositional proposals
can then connect to the learned fragment memory while preserving the same
teacher/receiver boundary, defaults, counterexamples and causal witnesses.
