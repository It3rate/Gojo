# Provisional equivalence, conflicting evidence and local revision

This small experimental fixture extends the native communication loop with
scoped assumptions. It tests whether a useful coarse reading can survive a
contradicted fine assumption, and whether an explicit context can choose a
working interpretation without hiding conflicting evidence or unavailable
engine capability. It is a finite candidate-selection and revision experiment,
not a trained concept-discovery model.

Open the [evidence gallery](../../experiments/QualitativeFrieze/results/equivalence-revision/gallery.html)
or the [all-stage overview](../../experiments/QualitativeFrieze/results/equivalence-revision/overview.html).

## Recorded run

Four cases contain ten stages and eight fresh acknowledged output executions.
Each executed output satisfies a separately communicated coarse four-edge
cycle promise through the history-blind motif reader. A fine span service
independently reads actual acknowledged strokes. It receives their explicit
role publications and actual graph, not desired span values.

| Case | First working state | New evidence or context | Result |
| --- | --- | --- | --- |
| E01 | Shared-span completion; source spans unreported | Horizontal participation `u -> u`, vertical `u` in one declared basis | Withdraw one span-equivalence edge, select unequal spans, retain the coarse cycle. Sending the distinguishing publication initially prevents the same repair. |
| E02 | One parameter shared across three closed cells; middle cell unreported | Middle horizontal span differs, outside cells agree | Select a local exception, carry ten pairwise equivalence edges and withdraw five; all three actual cycles remain. |
| E03 | Two suppliers disagree about the same roles and observation event | Explicitly select supplier A or B as the working route | No unqualified fine output for the full conflict. A conditional working output follows the selected route while both reports and conflict witnesses remain present. |
| E04 | Only the shared-span program is executable | Unequal source spans; then an explicit topology-only question | The finer request remains blocked. A separate coarse sample succeeds with the fine publication and failed exact request carried outside its selected read. |

The ten carried edges in E02 are pairwise consequences of the retained shared
parameter, not ten independent sensor observations. The parameter model stays
small while the expanded dependencies make the affected region inspectable.

Candidate selection first requires executable capability, no opposing working
equality evidence, no working fixed-sample mismatch and no unresolved
same-event literal conflict. Eligible candidates are compared on distinct
parameter count, native program participation and unrepresented requested
correspondences. Nondominated alternatives remain visible; an explicit
preference selects a working candidate. In the displayed cases the formal
correspondence-request scope is empty: active question selection is not tested.

Before any source span publication, E01's shared-span completion has zero
source equality supports and an open equality read. Its useful topology claim
and its provisional equality assumption therefore have different witnesses.
After the reveal, the older equality witness is preserved as a refuted
assumption, rather than rewritten into a claim that the current source agrees.

The next transmission is the actual source publication. The correction
history remains a separate native relation; a new receiver does not receive
the previous selection history as its message. This is an explicit refinement
rule, not learned message optimization. It currently transmits the observed
participation words; a later experiment can compare a smaller relation-only
distinction that leaves more proportions open.

The capture retains 84,826 native participants and zero numeric carriers or
locations. Its gzip archive is 743,772 bytes; restoration preserves reachable
participant count. The archive deliberately retains witnesses and execution
history, so these figures are not a compact-encoding or speed result.

## Structural contract

```text
domain = actual exposed roles -> shared unmeasured participation basis
publication = source -> (revision -> Closed(actual role -> participation word))
hypothesis = actual construction -> (role/parameter correspondences ->
             (sample parameter words -> proposed equivalence edges))
context = executable capabilities -> (selected question ->
          (working evidence scope -> native preference))

comparison = actual observations -> selected assumption
             -> (paired participation -> (unmatched -> unresolved))
assessment = hypothesis/context -> (supported -> (refuted ->
             (open -> (blocked -> conflicting evidence))))
revision = before -> (new evidence -> (retained assumptions -> withdrawn assumptions))
```

Repeated participation in a shared unmeasured basis is inspectable without
numeric carrier values. The comparison concerns the declared formal basis;
it does not establish a universal physical metric or Euclidean geometry.
Separate roles that agree remain separate roles. Shared parameter bindings
express an assumption about correspondence, not shared endpoint identity.

A publication's known word, an open word, a candidate's provisional parameter
sharing, and the concrete word realized by its output are different evidence.
Agreement in a generated sample cannot confirm an assumption about its source.
Different unknown reaches do not prove inequality.

Every candidate assessment retains literal support, opposition, unresolved
reads and blocked capability. Contradictory suppliers remain connected to
their actual sources and revisions. A selected working source scope is visible
in the context; it does not silently delete or overrule the other supplier.

Selection accounts for the selected question and executable capability before
using simplicity and an exposed preference. Simplicity is calculated from
native parameter participation. It cannot turn a disproved exact claim into a
supported one. A coarse fallback carries the finer blocked request or remainder.

## What an earlier square-like reading means

The independent topology reader can retain a closed four-edge route even when
a later source comparison distinguishes horizontal and vertical participation.
The earlier equal-span completion remains recorded with its assumptions and
the evidence then available. A refuted equal-span assumption is not a current
exact equality claim. A generated square-like icon may still satisfy a coarse
topology question while failing an exact span question.

The chosen screen interpretation makes the examples look like squares and
rectangles. Equal formal participation does not supply perpendicularity,
cross-axis physical calibration, interior fill or a general square theorem.
The captions describe that selected presentation. Native tests concern role
correspondence, participation, closure, dependencies and evidence scope.

## Questions for this run

- Can one revealing comparison withdraw a fine equality assumption while
  preserving a supported coarse closed-route reading?
- Can a repeated structure acquire one local exception while unrelated
  correspondence edges and witnessed closure remain supported?
- Can two incompatible suppliers remain visible while context changes the
  selected working interpretation?
- Can an incapable receiver keep the finer request blocked while offering a
  separately qualified lower-resolution answer?
- Can the failed assumption identify a more discriminating next publication,
  rather than teaching the receiver a hidden concept label?

These cases are intended as inspectable mechanics and counterexamples before
a larger training run. Learned policies can later choose assumptions, scope,
questions and message clauses. The native readers and accounting boundaries
should remain independently testable.

## Verification and current limits

```powershell
dotnet run --project experiments/QualitativeFrieze -- --equivalence-revision
dotnet test Tests/QualitativeExecution.Tests --filter "FullyQualifiedName~ProvisionalEquivalenceTests|FullyQualifiedName~EquivalenceRevisionTests"
node experiments/QualitativeFrieze/tools/check-equivalence-revision.cjs
dotnet test Gojo.slnx
```

The 25 focused tests cover native occurrence pairing, open/independent
participation, malformed or copied role bindings, source conflicts, capability
limits, ties, local dependency preservation, actual output conformance and
history-blind topology reads. Browser checks inspect all ten stage panels,
candidate comparisons, retained evidence, local links and desktop/mobile layout.
The recorded solution run passed all 4,466 tests, including the 25 new focused
checks. Browser verification covered four cases, ten stages, eight outputs and
seventeen local references with no console errors.

Publications passed to an assessment are its active evidence set. Earlier
events can remain in history; the fixture does not infer which event is current
or implement a universal newest-report rule. Concurrent contradiction is
recognized for actual shared event identity, with source identity preserved.

Role and participation-basis alignment is agreed by this fixture. It does not
learn alignment between independently encoded receiver domains. Candidate
programs, publication schedules and contextual source choices are authored;
there is no learned confidence, query policy, automatic hypothesis invention or
general truth-maintenance law. The next useful extension is a bounded policy
choosing an informative read or a smaller distinguishing message, evaluated
against these explicit conflict and capability cases.
