# Connected qualitative pattern generators

Implemented experiment, 2026-10-17. The experiment returns to elementary
connected generators rather than rhythm-to-motif expansion. It adds diagonal
chords, shared-site junction analysis, explicit period windings, graph
correspondences and declared aesthetic profiles above the existing kernel.
The generation and native analysis contain no numeric carriers or locations.

The [aesthetic rule note](GojoPatternAestheticRules.md) distinguishes primary
research from the authored thresholds used here. In particular, the directly
relevant [frieze study](https://journals.sagepub.com/doi/10.1177/20416695221131112)
supports examining visible relationships and strip-relative symmetry. It
does not supply universal weights or a target ink percentage.

## Connected mechanics

```text
supplier = (private phase cycle -> projection law) -> own occurrence history
port = (supplier -> receiver) -> (coarse basis -> closed signal domain)
publication = ((supplier -> (subject -> event)) -> (basis -> domain))
              -> (support -> opaque supplier evidence)
receiver law = finite law: coarse participant x actual column -> stroke support
receipt = actual publication -> (connection -> column support)
          -> (native law read -> (selected / blocked / unresolved))

site binding = actual site -> (actual column -> actual height landmark)
stroke = actual cause -> ((actual from site -> actual to site) -> chord word)
chord word = Closed(simultaneous actual move participations)
pitch promise = actual adjacent landmark edge -> shared unmeasured move word
period promise = actual column cycle -> repeated shared horizontal word
```

There are four ordered height landmarks. Explicit successor-to-move promises
give their adjacent steps a shared unmeasured reach; order alone would not
establish equal spacing. A diagonal combines horizontal and vertical
participation at one stroke. Longer height jumps retain repeated actual
vertical participation. Several independently placed stroke sets can draw at
once; no single continuous cursor is required.

The supplier projects its recurrence through a finite law and publishes only
the coarse support. EventScheduleConnection retains source and receiving
events separately. The consumer reads the advertised contract, support and
its own law; it does not read or refresh the supplier's private recurrence.
Tests exchange opaque supplier implementations with identical publications
and obtain the same receiver action. Wrong ports, foreign domains, open or
competing support and competing permit/deny rows do not become known actions.
Captured receipts retain and validate their actual domain and obligations.

The conditional ladder uses independent six-phase and three-phase suppliers.
The main supplier drives horizontal strokes; the second publishes an explicit
permit/deny/deny cycle to a branch receiver. Over six delivered events, that
receiver accepts two decorations and records four known denials. The gallery
shows the actual coarse publications and action receipts in a separate table.
These are non-draining observations and structural constructions, not material
carrier transfers or a general autonomous scheduler.

## Junctions and maps

Junction reads begin with actual shared-site incidence and outward chord
participation. Opposed and cooriented ray facts remain explicit.

| Display read | Native distinction |
| --- | --- |
| E | One incident ray: an endpoint. |
| I | Two opposed rays: a continuation. |
| L | Two distinct, non-opposed rays: a bend. No right angle is assumed. |
| T | Three distinct rays with an opposed pair. |
| Y | Three distinct rays without an opposed pair. This is a coarse family, not a 120-degree or occlusion claim. |
| X | Four distinct rays covered by two opposed pairs. |
| O | A witnessed zero-return graph cycle from a finite cycle basis. It does not establish a circular shape, enclosed area or white region. |
| Winding | A graph cycle whose displacement cancels against the explicit whole-period word. It is separate from O. |

The current winding reader certifies plus or minus one explicit period;
other unexplained returns remain obligations. Open chord tails remain open
inside cycle proofs. Duplicate parallel edge participants can form a multigraph
cycle even when a measured view retraces them, so the separate geometry check
remains necessary. Unused declared sites are coordinate landmarks, not isolated
ink components or white-space regions. Missing or foreign incidence appears
as cuts and obligations; intentional stroke endings are endpoints.

Supplied site, stroke and chord maps must be total bijections, preserve ordered
endpoints and retain opposed/cooriented chord facts, including disconnected
chord pairs. Tests reject a T-to-Y relabeling. Native graph correspondence is
still distinct from Euclidean isometry. A separate measured supplier verifies
selected translations, mirrors, half-turns and glides. Retained phase
permutations are proposals; this experiment does not certify that they preserve
all producer and receiver laws.

## Scoring and the useful failure

The generic profile reads actual criterion supports as preferred, acceptable,
known violation or unknown. Every result retains its criterion and observation
witness. The native profile observes vocabulary reuse, endpoint count,
occupied junction signatures and supplied nonidentity graph correspondences.
Its cardinality bands are visible finite slot scopes. Optional measured
criteria observe empty probes, clearance-center spread, ink isometries and
multiple-support crowding. See the rule note for exact authored thresholds.

Each preferred criterion contributes two diagnostic points, each acceptable
criterion one, and a known violation zero. Unknown input has no rank. Native
and measured ranks each have a maximum of eight; the displayed total has a
maximum of sixteen. Ranking requires both profiles to be complete and
acceptable, and measured centerlines to have no positive-length retracing.
Crossings are allowed by this profile.

The first seven-criterion profile gave the crossed braces 13/14 even though
the width-two rendering almost erased its gaps. About 69% of probes had multiple
stroke support. This was a useful counterexample: symmetry, vocabulary and
even clearance can reward unreadable density. The revised profile adds a
crowding preference at at most 20%, allowing at most 35% for selection. These
are visually motivated experimental bounds, not empirical laws. Ordinary
joined pen strokes can have multiple support without retracing.

## Recorded examples

The eight primary constructions have eight additional authored one-phase
variations. Each variation changes one main coarse projection binding while
preserving the other category sequence; it has an independent world and event
history, not an exact parent-child patch correspondence.

| Primary construction | Native /8 | Measured /8 | Total /16 | Selected profile accepts |
| --- | ---: | ---: | ---: | --- |
| Four-level chevron | 7 | 6 | 13 | No: too sparse in the chosen probe band |
| Counter-moving chevrons | 7 | 6 | 13 | Yes |
| Diamond lattice with upper branches | 8 | 7 | 15 | Yes |
| Crossed braces | 8 | 5 | 13 | No: crowding |
| Alternating forked ladder | 6 | 8 | 14 | Yes |
| Glide-related diagonal fans | 8 | 6 | 14 | Yes |
| Terraced diagonal bays | 7 | 5 | 12 | No: too sparse in the chosen probe band |
| Conditionally pruned ladder | 7 | 6 | 13 | Yes |

All sixteen have zero measured centerline retraces in this interpretation.
Ten satisfy the selected profile. The diamond construction has native T, Y,
L and X reads together with two zero-return cycle witnesses. The paired
chevrons have two measured crossings and no native X junctions: intersecting
ink did not fuse their source sites. The fans supply a nontrivial glide, while
the terrace supplies translation without the additional tested symmetries.
These are verified selected maps, not a complete classification into all
seven frieze groups.

The deliberately open publication example retains one source obligation,
four unknown native criteria and an unavailable score. Its known stroke prefix
and open remainder survive; neither a rest nor a hidden private read repairs it.

## Measured interpretations

The main view interprets the shared H/V reach as four ticks, uses a round pen
of width two, and samples a radius-one observer in the common y-band -2..14.
The supplier keeps actual stroke provenance, periodic copies, calibrated
axes, probe cells, occupancy and ordinal-clearance evidence. Probe fractions
are not exact continuous area. Rails are outside these reads.

Alternative views keep the exact native sources and change the pen-to-pitch
calibration. For crossed braces, pitch 8 lowers multiple support to 38.4%;
pitch 12 lowers it to 18.9%, while the native score stays 8. At pitch 12, the
clearance-spread criterion still fails. For the fans, pitch 8 reduces crowding
but increases empty fraction and clearance spread. A finer-looking rendering
does not automatically satisfy every chosen preference. These are alternative
metric choices permitted by the same unmeasured source, not an automatic
precision policy.

The sixteen candidates and unknown example's native evidence contains 68,810 elements,
zero carriers and zero numeric locations. This is an identity-visited graph
count, not a packed storage size or performance benchmark. The optional probe
and geometry evidence is larger. No kernel code changed.

publication/action table.
