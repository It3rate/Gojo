Suggested sequence · 2026-09-15

Experiments and the work between them

Start with small systems whose behavior we can inspect, then ask whether they can predict, choose useful work, reuse skills, and change their connections. Build the missing mechanism just before the experiment that needs it. This is a suggested order, not a requirement to obtain a positive result at each step.

Steps 01–03 establish what happens and whether predictions hold up. Steps 04–08 explore useful observation, activity, memory and reuse. Sorting supplies a different task; repair and search then ask how the organization itself can change.

Experiment 02 · Explored

Find the limits of two-space feedback

Completed 24 conditions in three fresh worlds each. All 72 runs matched the independent exact reference. Quarter responses became quiet with a remaining gap; finer and coarser ticks changed that gap. Timing, missing messages, reference selection and controller limits remained distinguishable in the records.

Numerical agreement is a correctness check. Any Gojo benefit must be demonstrated in inspectability, composition, retained information, adaptation or measured cost.

Experiment 03 · Explored

Make predictions that can be wrong

Twelve fixed cases completed with no differences from the exact reference. Line continuation predicted the unequal-time ramp exactly but lost to hold-last on alternating values and a sudden step. Old predictions survived new fits; five blackout forecasts remained unassessed.

Fitting a selected family is not discovering that family, and fitting past data is not predictive success.

Let observations guide work

Build before experiment 04

Extend the existing Gojo pair observer with explicit goals and read requests, using focus, ports and timelines. Keep passive observation separate from a connected request for finer information. Preserve both paired snapshots and intermediate events; full world replay is unnecessary.

Experiment 04 · Next

Test when a broader view is useful

Can an observation of the whole help predict a disturbance or decide when to look closer?

Try
Present quiet agreement, balanced internal motion and a later disturbance. Compare a coarse view, a fine view, and a coarse view that requests detail under a stated rule. Score prospective warnings or a specific intervention on new trajectories.
Observe
Missed disturbances, false alarms, response delay, extra reads and unresolved detail. Ask whether the broader view improves a decision, not merely whether its plot looks simpler.
Controls
Use the same inputs and work allowance; include always-fine and fixed-interval inspection. Removing the observer's action connection should remove its influence while preserving its read.
Ready when
Observer access, goal, request and resulting work are visible in structure. Passive observation does not change the participant.

A useful view is relative to its task and access. It does not establish a universally privileged scale.

Build before experiment 05

Minds: generalize exposed publication links to a small three-space network. Reuse source/event identity, provenance and shared-source bounded quantities. Add only missing correspondence reads needed to distinguish a known shared source from an opaque source; do not invent a universal trust score.

Experiment 05 · Planned

Add a third source and test echoes

Can several views combine without treating a repeated message as new independent support?

Try
Compare three separate observations, one observation arriving by two known routes, and an opaque source with unknown ancestry. Include conflicting references, a broken link and unequal resolutions.
Observe
Agreement, reference mismatch, source coverage, unresolved dependence, circulation of old messages and communication cost. Keep observation fanout distinct from material transfer.
Controls
Disconnect links and compare shared-source versus genuinely separate sample events. Distinct identities alone do not establish statistical independence. Conventional controls retain equivalent dependency information.
Ready when
Known aliases are preserved; opaque sources remain usable without fabricated independence; transferred material, if introduced, is not duplicated across branches.

Correlation-based trust and source reliability learning remain separate future laws.

Build before experiment 06

Express a local goal, tolerance, pending work and wake condition through Gojo repeat/control structures. Add work counters and a small scheduler that follows exposed requests. If an attached recurrent world is used, expose settlement pass/budget evidence without changing settlement laws. Idle must not mean no unresolved structure exists.

Experiment 06 · Planned

Settle, do less work, and wake again

Can a system reduce its activity when its goal is met and resume useful work when conditions change?

Try
Long quiet periods interrupted by small and large changes, including changes hidden by a constant average. Start with a stated wake rule; learning that rule is a later condition.
Observe
Read and update counts, messages, wake delay, missed changes and goal satisfaction over time. Report wall time separately; changes in values are not measurements of physical energy.
Controls
Compare always-active and fixed-period polling with the same input stream and information access. Include a coarse wake rule that can miss fine activity.
Ready when
A quiet state with remaining residue is distinguishable from an exhausted work allowance. New input can reactivate work through an explicit route.

A successful authored wake rule is not evidence that Gojo learned an attention policy.

Build and reuse skills

Build before experiment 07

Follow the existing signal-learning direction: connect candidate models to their issued predictions, later outcomes, support, cost and selection or mixture rule. Define those local update laws before measuring them. Add a memory port with source, time and resolution so remembered observations remain distinguishable from new measurements.

Experiment 07 · Planned

Keep competing predictions and useful memory

Can past usefulness change which local models contribute, while preserving alternatives that may become useful again?

Try
Offer a small stated set such as hold-last and affine continuation. Change the signal regime, restore an earlier regime, and introduce gaps. First retain exact recent history; test deliberate compression only as a separate condition with a declared loss.
Observe
Future error, coverage, switching delay, cost, discarded alternatives and recovery when an old pattern returns. Keep ambiguous candidates visible when observations cannot distinguish them.
Controls
Compare each fixed model, equal contributions, and the same selection rule without history. A retrospective best model can be an evaluator-only upper benchmark, never participant input.
Ready when
Support changes have an explicit action/outcome basis; candidates cannot learn from outcomes not yet received; loss from forgetting is visible.

Selection among supplied models is learning within a chosen vocabulary, not unrestricted model discovery.

Build before experiment 08

Reuse Gojo patterns, ports, transforms and dependencies to connect calibration, prediction and response. Add missing application and revision witnesses. A reusable shortcut needs a stated domain, retained source correspondence, an equivalence check and a path back to detailed work when its premises fail. Crystallization alone does not discover a replacement equation.

Experiment 08 · Planned

Combine skills and reuse the combination

Can a useful combination become an exposed operation that works in another setting?

Try
Compose two already tested operations, expose their combined input/output, then connect that operation to a third. Transfer it to different units, ranges and signal timing. Test inputs outside the promised domain as well as compatible ones.
Observe
Transfer accuracy, adaptation work, construction cost, retained uncertainty and reactions to stale dependencies. Compare the full structure with a proposed shortcut before replacing anything.
Controls
Compare rebuilding from primitives, using a frozen combination, and an ordinary implementation with equally reusable modules. Match the allowed interface adaptations and count the cost of discovering the original skill.
Ready when
The combination remains readable after removing its helper class. Unsupported inputs remain unresolved or trigger explicit revision, rather than receiving a memorized answer.

Begin with authored composition. Discovery of which skills to connect belongs to the later search experiment; a new wrapper name alone is not a new skill.

Test organization in another task

Build before experiment 09

Add a reusable Gojo movement contract: occupied sites, legal neighbors, cell identity, atomic swaps, conflicts and ties. Define separately a part that cannot initiate movement and a part that cannot be moved. Pin the sorting study's implementation before claiming replication; a changed scheduler is a stated variant.

Experiment 09 · Planned

Sort with local rules and damaged parts

What ordering can local moves achieve, and how does damage change the reachable outcomes?

Try
Start with small exhaustive arrays and one local rule. Add each defect separately, then larger cases. The runner schedules legal attempts; it must not sort a host array and write answers back into Gojo.
Observe
Attempted and completed moves, adjacent descents, total inversions, source-study measures and unreachable goals. Retain full trajectories and cost, including failed attempts.
Controls
Use a conventional implementation with the identical movement and defect rules. Check reachability in tiny cases. A temporary worsening in one measure may coincide with improvement in another, so it does not by itself demonstrate foresight.
Ready when
Moves preserve cell identity and occupancy; conflict and immobility checks pass independently of whether sorting succeeds.

This is the most direct link to the sorting work discussed in Ingressing Minds. It can branch after step 02 if that comparison becomes the priority; it does not depend on all memory and skill work being finished.

Build before experiment 10

Extend the tested movement contract to a stated mixture of local rules. Add independent clustering measures, inert comparison labels and matched label-count randomizations. Keep the rule each part executes separate from labels used only by observers.

Experiment 10 · Planned

Mix local sorting rules

Do useful patterns appear when parts following different rules share one space?

Try
Mix rules at several stated proportions, vary starting order, and repeat with each defect law. Inspect clustering, sorting, deadlock and temporary reversals of progress.
Observe
Ordering and clustering over time, dependence on initial layout, work and the cases where mixtures perform worse. Distinguish a predicted pattern on new arrays from a pattern noticed afterward.
Controls
Compare pure-rule arrays and identical rules with inert random labels. Match movement opportunities and schedule; labels must not become a hidden attraction rule.
Ready when
The observer can detect clustering in a constructed positive check and avoid reporting it as a rule effect in the inert-label controls.

Clustering alone does not establish cooperation, a shared goal or a new mind. Its contribution must be tested by intervention.

Let organization change

Build before experiment 11

Define legal proposals to attach, detach or redirect exposed relations, plus local capacity, cost and ownership. Connect proposals to goals, accepted/blocked changes and later outcomes. Start with a small fixed edit vocabulary; general growth and decay laws are not yet established.

Experiment 11 · Planned

Repair and change connections

Can local connection changes recover useful behavior after damage, and at what cost?

Try
Remove a link or participant from a working small network. Compare recovery through a spare route, local edit attempts, and combinations of previously tested skills. Include damage for which the allowed edits cannot achieve the goal.
Observe
Recovery of the selected task, unnecessary edits, cost, oscillating reconfiguration and remaining disconnections. A local condition such as two neighbors per part is not proof of one connected whole.
Controls
Compare no repair, a fixed repair rule and a random legal edit policy with the same information and work budget. Keep any central observer's extra knowledge out of local repair decisions.
Ready when
Edits preserve structural contracts, do not create free conserved participation, and retain failed proposals. Later utility has a traceable connection to the change being assessed.

Recovery must be measured against the task; merely restoring a familiar-looking graph is insufficient.

Build before experiment 12

Use the legal construction and edit vocabulary from earlier experiments. Separate candidate proposal, evaluation and selection; record every attempted candidate and its cost. For a confirmatory comparison, freeze the heuristic definitions, task splits and assessment before evaluation. Neither replay nor a numeric compiler guard is required unless the specific claim depends on them.

Experiment 12 · Planned

Compare ways of discovering useful structures

Do the proposed heuristics find transferable combinations more efficiently than simpler searches?

Try
Compare reuse of prior skills, search guided by unresolved local work, random legal proposals and a stated conventional search. Train or develop on one set of feedback, prediction or sorting tasks; evaluate on unused tasks and changed combinations.
Observe
Useful new operations found per budget, held-out performance, transfer cost, failure rate and the cost of maintaining the search itself. Report the whole search, not just the best surviving example.
Controls
Give each search the same construction vocabulary, observations, legal actions and evaluation allowance. Count prior skill-building work or report it separately. Test removal of each proposed advantage.
Ready when
A run can end with no useful discovery and still be valid. A changed rule creates a new condition whose claim is tested on fresh cases.

This tests practical research heuristics and structural learning. It does not distinguish metaphysical explanations that make the same observable predictions.

Shared rules

  • Keep the question, selected rules, information access and observation window with each run. Save surprises and amendments; use unused cases to evaluate a revised claim.
  • Separate agreement, goal satisfaction, ongoing activity, unresolved work and the end of observation. A system can meet a goal while parts continue moving.
  • Use Gojo observers where practical and independent small-case checks to validate them. A broad observer may inspect more than an individual participant, but that access must be declared.
  • Decimal calculations are allowed at declared interfaces. Exact replay and compiler guards can wait until a particular question needs them.
  • Compare the same information, actions, resolution and resource budgets. Conventional exact arithmetic and conventional graphs can represent uncertainty and history too. Floating-point arithmetic is an additional condition, not a stand-in for all ordinary mathematics.

Build later, when a question needs it

  • Exact continuation and replay when diagnosing a difficult divergence or promising a restorable checkpoint. Gojo numeric graph transport is a starting point; host queues and external inputs require their own capture.
  • Compiler-aware numeric boundary checks when making a claim about an entire calculation path. Keep legitimate sensor and external-tool adapters explicit rather than banning decimal interfaces.
  • Probability, learned reliability, continuous dynamics and richer geometry only when a question needs their additional laws. Bounds, tolerance, output resolution and confidence must remain distinct.
  • Preregistered confirmation once exploratory behavior supports a specific claim. Keep earlier runs and amendments; do not redefine success to rescue a disappointing comparison.
