Gojo · preference transfer and recovery

A useful guess in a new situation

A machine learns which option helped in one construction, then tries a corresponding option in another. Sometimes that saves a poor first pass. Sometimes it imports a bad guess. The new world keeps moving while its own complete passes revise the preference.

1 · Learn a useful preferenceA retained source pass supports an option that improved or met its local goal.
2 · Map the option, not the truthA supplied correspondence suggests which target option to try first. It does not establish the target’s motion law.
3 · Let the target revise itThe target makes its own passes, with its own evidence, actual state and unresolved tension.

What crosses into the new context

Only a provisional preference is imported. Source evaluations remain source evidence. The target begins with its own empty evaluation history and unresolved motion candidates. An option’s position in the table is not its meaning.

Scope of this transfer

The controller reuses a preference through a supplied structural correspondence. This experiment does not discover the analogy, invent new motion candidates, or learn a universal ornament-quality measure. Different constructions exercise the same small decision mechanism. The target must establish its own utility through actual passes.
