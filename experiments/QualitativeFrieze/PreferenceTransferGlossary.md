# Machines in the preference-transfer experiment

## The short version

The source learns an option preference. A correspondence connects that option
to an option in a new machine. The new machine tries it provisionally, acts
through a complete pass, evaluates its own discrepancy, and keeps or changes
its preference. Source evidence, target evidence and the analogy between them
remain separate structures.

## The connected pieces

| Piece | What it does | Native representation / limit |
| --- | --- | --- |
| Source pass memory | Retains or advances an option after a whole pass. | Ordered option scope, wrapped phase carrier, comparison claims, finite law, two retained pass witnesses. |
| Useful preference export | Captures an option that just improved or achieved its source goal. | Source surface, context, option domain, frozen phase coordinate, selected option, qualifying pass witness. A default or untried next option cannot supply it. |
| Correspondence | Names which target option plays the proposed source role. | `(export -> target policy) -> Closed(target context, target option domain, source-option -> target-option rows, premise)`. Authored hypothesis, not target truth. |
| Preference import | Moves a fresh target's preference to the mapped option. | Explicit route to the target phase port; positional delta enters through carrier settlement. Witness retains the mapping, transition and open target applicability. |
| Candidate response read | Asks what each target motion interpretation would do now. | Candidate-to-response relations and finite response selection. Import does not add motion support. |
| Pending-adjustment gate | Makes outstanding tension matter to later commands. | Exposed pending port and finite gate law; debt is not cleared at a pass boundary. |
| Extent machine | Applies an admitted signed step. | Public response port, finite transition law, local clamp, carrier value/tension and timeline. |
| Calibrated publication | Reads extents into a drawing construction. | Port-to-ordered-frame projection. In reversal, `S(h,0,12) -> S(common,12,0)`. Observation does not transfer material. |
| Height evaluator | Measures the selected gap discrepancy over the pass. | Existing geometric gap/landmark claim with captured before/after observations. |
| Width evaluator | Measures the endpoint discrepancy over the pass. | Existing endpoint claim. It sees the joint outcome but cannot yet isolate who caused it. |
| Target pass memory | Revises the imported starting preference using target utility. | Same keep/advance grammar as the source, with a new context and fresh local history. |

## Reading the replay

**H** and **W** are the two local controls. The viewer numbers options from one;
the source code indexes them from zero. An option number has meaning only in
its local option domain. The arrow between source and target option numbers
shows the actual supplied correspondence, not a claim that matching numbers
are equivalent.

**Preference after evaluation** is the option that the next pass will try
first. It is not necessarily the option just used, and after a failed pass it
may not yet have useful evidence of its own.

**Two candidates** means two possible motion descriptions remain. It does not
mean two physical commands were sent. A provisional choice selects one allowed
response without deleting the competing explanation.

**Gap** is the primary geometric section read. **Landmark gap** can survive
when a section disappears. The viewer's diagnostic value is not automatically
available to the controller; the withheld case makes that separation explicit.

**Tension** is unabsorbed change, not a score. In the reversed experiment,
height 12 with tension +1 must receive one negative step before its visible
height can decrease. **Pass utility** is a separate comparison of before/after
discrepancy in one context.

The preference cursor has its own wrapped carrier. Crossed complete cycles
remain visible there as whole-cycle tension; they are not actuator debt and
are not included in the height/width tension plot. Restoring that valid wrapped
state preserves the cycles instead of clearing them or rejecting the memory.

**Jointly settled** means the report found the desired primary gap and endpoint
coincidence with zero pending height and width tension. It is a diagnostic
read of both goals, not a new global controller.

## What this vocabulary does not imply

There is no new hexagon, diamond or general analogy-learning machine here.
The shape templates, options, mappings and keep/advance law are supplied.
The new capability is accountable preference transfer and target-local
revision. A mechanically valid mapping can fail in practice, and a useful
pass does not identify a unique motion law.
