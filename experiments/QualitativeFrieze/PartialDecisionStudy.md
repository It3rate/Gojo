# Acting with partial information, then making another pass

## What this experiment does

A small ornament has two independent controls: one changes height and one
changes width. Each begins with two possible descriptions of its movement.
Instead of requiring a unique explanation, we now compare shared responses,
explicit provisional choices, and short coordinated trials. We then let the
actual changed world continue through several complete passes.

The useful new result is that **a controller can reach its goal while still
retaining two possible motion explanations**. A bad provisional pass can also
leave enough evidence to change the next preference. The bad pass is not
rewound: its values, lost section reads and pending tension carry forward.

Open the [interactive replay](results/partial-decisions/index.html). Start with
**Opposed motion possibilities → Provisional choices + pass memory → Inset cap**.
Compare it with **Keep the initial provisional option**, then with

The [machine glossary](PartialDecisionGlossary.md) explains the actual connected

questions and limits before the campaign.

## What a pass means here

One pass is six clock opportunities for the two controls over the whole small
construction. There are six passes in a run. It is not a traversal of every
possible construction or a search through all future states.

Each control has its own perspective. Height evaluates the selected landmark
gap against its goal. Width evaluates the selected endpoint discrepancy.
Both observe the construction before ordinary responses are applied. Changes
to one can alter the next observation available to the other.

The body of the experiment carries the same actuator state forward. Only
explicit signed inputs change its values and tension. There is no automatic
rollback or reset between passes. Geometry is still re-read from the connected
role-bound construction; this is not yet persistent material deformation.

## Five ways to run the same supplied situation

| Mode | Permitted behavior |
| --- | --- |
| Unique explanation | Act only after one supported motion candidate remains |
| Shared consequence | Act when every remaining supported candidate gives the same response |
| Fixed provisional choice | Use shared responses, otherwise keep the first eligible provisional option |
| Revise after each pass | Use shared responses, otherwise retain or advance a provisional preference after local pass evaluation |
| Combined choices and trials | Add bounded local trials, exact quiet grants and motion evidence to the pass policy |

The fixed and revising modes have different native finite-law rows. Their
runtime behavior is read from those rows. In both, a provisional choice is
kept separate from an observation about the world.

The campaign crosses nine supplied situations, five modes and two source
constructions: 90 runs, 540 passes and 3,340 recorded frames. Some situations
only perturb the trial mechanism, so several control-mode results are
identical. These are paired mechanism tests, not 90 independent natural tasks
or an aesthetic benchmark.

## 1. Agreement can be useful without a unique construction

The equivalent-word situation supplies two actual calibration interventions to
every mode before the passes. Each supports two distinct motion words that
reduce to the same displacement. One word includes a cancelling excursion;
the other does not. Their identities and construction remain different.

Unique-only control stays at its post-calibration state. Shared-response
control reaches both goals in both construction families, without further
identification trials and without removing either candidate.

This is agreement under a selected candidate scope and read. It does not prove
all conceivable constructions agree. Unsupported or unreadable alternatives
cannot be dropped merely to manufacture unanimity.

## 2. A poor full pass can change the next choice

In the opposing-word situation, the declared first option has the wrong
motion polarity. The fixed-choice baseline continues to prefer it and fails.
The pass-revised policy changes preference after the first complete pass and
reaches both goals during the second pass, in both families.

The inset trace is especially direct:

| Complete pass | Landmark gap, target 12 | Endpoint discrepancy, target 0 | Local response afterward |
| --- | --- | --- | --- |
| Start | 6 | −2 | Two unsupported explanations per control |
| 1 | 6 → 3 | −2 → −10 | Both local discrepancies worsened; advance each preference |
| 2 | 3 → 12 | −10 → 0 | Both selected goals reached; retain preferences |
| 3–6 | 12 → 12 | 0 → 0 | Keep the useful options |

In the separate lost-section case, the inset's original section gap becomes
unreadable during the poor pass. The landmark question remains available and
can guide recovery. The chevron starts with its section already collapsed.
The next pass can therefore start with different available observations as
well as different values. The displayed pass-gap table uses the landmark
question; it does not turn that into a successful section read.

Both motion candidates remain throughout these runs. No isolated motion
trial took place. What changed was a local policy preference under this pass's
conditions, not a conclusion that one motion explanation had been proven.

The preference law itself is supplied: keep an option after improvement or
achievement, advance after a stall or regression, and preserve an unreadable
evaluation. This is a small adaptive mechanism, not a learned general policy.

## 3. A trial is a coordinated action, not a private peek

The trial machine receives finite positive and negative offers. Feasibility is
read from exposed extent, pending tension and the actual attached boundary.
Candidate words supply predicted distinctions. Native laws select an eligible
offer; an exact quiet grant is required before allowance is spent.

In the capacity case, height starts at its upper boundary. A positive trial is
unavailable, so the local machine selects a negative trial. It learns the motion
effect, but the height capacity still prevents the geometric goal. Knowledge
does not create capacity; the unmet change remains held as tension.

Delayed grants produce a more informative failure. While a request waits,
ordinary provisional responses can keep changing the scene. In the recorded
inset run, the height trial at beat 5 only repays negative tension and produces
no visible movement. It does not eliminate either candidate. A later trial at
beat 11 is informative. The final goal is reached, but the failed first probe
and its spent allowance remain visible.

Refusing quiet permission prevents trials, but does not prohibit separately
permitted ordinary guesses. The combined controller can still settle through
pass-level revision while retaining both motion explanations.

## 4. Utility survives some failures of identification

The confounded case deliberately changes the other control despite the quiet
route. Actual before/after state exposes both changes. All four attempted
trials in each construction family are uninformative for identifying a single
input's effect; both motion candidates remain.

Nevertheless, the complete-pass policy reaches the goals in both families.
This is the clearest separation in the study: **useful action does not require
successful identification in every case**. It also does not justify pretending
the confounded trials identified anything.

Each pass retains its actual provisional, shared and trial uses. Its outcome
is contextual utility under those combined influences. It does not assign
independent causal credit to each participating choice.

The finite alternatives deliberately include a useful motion description, and
the geometry is small and supplied. These results test composition and limits;
they do not establish discovery of arbitrary machines.

## Memory, changing context and honest loss

Each active policy keeps two recent pass evaluations. Older detail is released
with a native discard count and an open lost-history surface. Some retained
entries are unresolved records of choices that were proposed but never used
because a trial took their place. The count is not a count of useful successes.

At the changed goal, new policy contexts are explicitly constructed. The old
context archives remain separate; the new preferences begin afresh. Motion
evidence remains usable because this intervention changes the goal rather than
the motion law. Pass-only control incurs another poor pass while revising its
new preference. Transferring a learned preference between contexts is still a
next experiment, not silently assumed here.

Two recent evaluations per memory does not mean two records in the entire
apparatus. Actuator timelines, finite trial histories, retired contexts and an
optional diagnostic archive have different retention promises. The measured
operational exports are 158,701–1,169,105 bytes. Four full evidence exports are
about 3.5–3.8 MB each. These are verbose native experimental archives, not
minimal compiled machine sizes.

Response counts include hold commands and repeated uses after the goal is
reached. They are not independent discoveries or units of artistic quality.
The present clock continues through its declared pass budget; learning when
to stop spending attention is another useful gap.

## What changes, and what still does not

The selected response route can change. Movement changes which questions are
readable. Explicit goal-context replacement changes which evaluation history
applies. The experiment does not rewrite path topology, invent new candidate
words, grow new ports, or learn new evaluation criteria.

Both source families use the same controller grammar through different
bindings. That supports reuse of the mechanism, but not yet learned transfer
of a metaphor between unrelated domains. Next useful tests are context-aware
reuse, richer trials when two inputs cannot be isolated, and neighboring
motifs whose local goals conflict instead of all being jointly satisfiable.
