Four connected mechanisms: prospective protocol

What we are trying to learn

The first settlement study found that a small comparison-driven machine can follow another machine, but it keeps requesting growth at capacity, acts on old messages, and has no way to choose between competing goals. We will add four explicit mechanisms and compare their behavior with the earlier versions. The fourth asks for a geometric separation rather than a target picture.

This protocol is written before running the new campaign. These are authored mechanisms and supplied test conditions, not discovered laws or learned taste.

The four steps

  1. Pending-adjustment gate. Advertise the actuator's signed held tension. A finite law holds a request when it points in the same direction as already pending change. An opposed request remains permitted. Repeated observations are not repeated physical imports unless this explicit response permits them.
  2. One outstanding request with acknowledgement. Retain one observation until its delivery is processed and the corresponding receipt returns. A new comparison is sampled after that acknowledgement. This is a supplied scheduling protocol, not a prediction of future source changes.
  3. Response arbitration. Two observed desires meet an explicit agreement or priority law. Conflicts and nonselected evidence remain visible. Priority may select one outcome; it cannot make incompatible goals jointly true.
  4. Geometric gap claim. Observe actual native straight-section words in one selected basis, compare their separation with an advertised gap, and connect the result to a declared correction direction. Unsupported geometry stays unresolved. The renderer and target outline supply no decisions.

The order matters. A receipt acknowledges that an observation was processed, not that its goal was reached or that all tension disappeared. A suppressed request is accounted as a response decision, not as newly transferred material.

Predictions and controls

  • With a constant unreachable goal, the pending gate should limit repeated debt accumulation to the first blocked unit. It should not claim success.
  • A reversal should account for retained debt before visible change. Missing pending information should remain unresolved rather than reading as zero.
  • A single outstanding comparison should remove the pipeline of contradictory old self-corrections against a fixed target, at the cost of slower response. A source that changes while a message travels can still make it stale.
  • A lost receipt should leave the channel waiting. Duplicate or unrelated receipts must not create new capacity or release another request.
  • Agreement-only arbitration should expose incompatible goals. Priority should favor the selected source and retain the other goal's mismatch. A favorable terminal value alone does not establish fairness or joint satisfaction.
  • Gap feedback should reach representable separations with a permitted motion and adequate capacity. Nonparallel or unsupported sections, absent evidence, or an unattainable gap should remain visible failures.
  • The same native laws and compact reads should agree. Saved compositions should retain live port aliases, event identity, pending state and behavior.

Supplied guidance and measurement limits

We supply the response laws, native section roles, unit correspondence, motion direction, goals, capacities and clock/delivery schedule. The host can schedule messages but cannot replace the selected law's answer. Exact scalar comparisons are local sensor reads; only coarse comparison support reaches the actuator.

This uses the current small integral carrier system and unary drawing words. It does not retrofit exact magnitudes into a historical participation bit. Observed gap discrepancy is residue of a claim; only an admitted correction introduces a signed adjustment. Neither gap error nor repeated observation is automatically conserved material.

We will record each initial condition and every delivered comparison, selected response, pending adjustment, acknowledgement state and observed shape. Report goal agreement, unresolved evidence, debt and delay separately. Each mechanism will have a glossary entry explaining which relation actually does the work.
