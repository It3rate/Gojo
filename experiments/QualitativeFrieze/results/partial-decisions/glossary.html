Machines for partial decisions and complete passes

The simple picture

Two controls change the lower half of a small ornament. Each has several possible descriptions of what its movement will do. It can use a response the supported descriptions agree on, make an explicit provisional choice, or ask for a short experiment. After a complete pass, a separate small memory can revise which provisional option it prefers next time.

The controls keep moving in the same world. A bad pass is not erased and the next pass begins with the actual resulting values and tension.

Shared consequence and provisional choice

    -> finite agreement read

proposal -> chooser -> selected candidate -> selection evidence
    -> one provisional response

The response publications use the existing local comparison basis: 001 decrease, 010 hold, 100 increase. These are compact reads of native support scopes, not new meanings assigned to the original ODV bits. An open support is not a measured zero, and a hold can be a gate's refusal to accumulate more pending change rather than satisfaction of a geometric goal.

For shared action, every remaining candidate must have retained informative support and a readable singleton response, and those responses must agree. Candidate identity and construction remain available. A closed empty set is not universal agreement. A missing or unsupported candidate cannot disappear merely to make the others unanimous.

An explicitly permitted provisional selection can use an unsupported but readable candidate. FiniteChoice retains the whole original proposal. The candidate-response reader checks that the selected candidate is still possible and that the proposal belongs to the current observation. A selected response does not add an observation to the motion learner.

A pass preference and a per-beat command are separate. The pass retains its chosen option; every beat must select that option again from the current proposal. If it is no longer offered, that beat remains unresolved. A command cannot reuse an old proposal as permission to ignore changed observations.

An offer includes explicit observations about feasibility and whether the candidate predictions differ. The supplied fixture reads the actual exposed extent, pending tension and attached capacity, and retains the candidate words behind its prediction. These are bounded local reads, not a score based on the private desired drawing. The positive/negative candidates here are linear, so both signs distinguish the same models when movement is possible; feasibility is what makes one direction preferable at a boundary.

The allowance is consumed once at dispatch. Waiting for a grant does not spend it. A copied-looking or stale grant is not the held request's permission. Completion checks the actual dispatched packet and native transition, including a consumed event. Zero accepted change is a completed but uninformative trial.

The other control's actual accepted change and held tension are checked before claiming single-input isolation. A deliberately bypassed quiet route can leave both inputs changed. That observation retains confounding and cannot eliminate motion candidates. The protocol still does not establish absence of causes outside the published experimental scope.

Height evaluates its selected landmark-gap discrepancy. Width evaluates its selected endpoint discrepancy. These are distinct perspectives. A successful landmark comparison does not certify a valid section gap or a material join.

The supplied adaptive law retains the selected option when the discrepancy shrinks or reaches zero. It advances through the declared option order when the result stalls or worsens. Unavailable observations leave the evaluation open. A fixed-choice control has different native law rows: always keep. The runtime does not dispatch on a policy name to decide the outcome.

Each evaluation connects the start/end claim witnesses to the option used, actual decision/transition witnesses, pass context and cursor transition. Other responses and trials during that pass remain visible. Improvement is performance of this contextual pass, not proof that one chosen explanation caused all of it.

Only two pass evaluations remain in each active policy memory. A native discard count and open lost-history surface record deliberate forgetting. Duplicate exclusion covers that retained window; this is not a permanent global event ledger. Retired goal contexts and actuator/trial histories remain separate, so the entire apparatus is not claimed to have a two-record memory.

Reuse and metaphor

The same decision grammar is connected to inset and chevron constructions. The controller operates on exposed discrepancies, allowed responses and trial evidence, not on the words “inset” or “chevron.” Those names select the supplied source fixtures only.

This is a foothold for learning the usefulness of a machine across contexts. It does not yet discover the correspondence between domains, invent new machines, or transfer a trained preference without an explicit binding. Construction, observation, policy selection and historical use remain different parts of the glossary.
