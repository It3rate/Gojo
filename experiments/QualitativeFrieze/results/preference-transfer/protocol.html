Learned preferences in new situations: prospective protocol

The question

Can a small machine use a preference learned in one situation to make a useful first guess in another, notice when that guess was poor, and adjust through further complete passes? The target is reuse with visible limits. A successful source pass is a reason to try a mapped option; it is not proof about the new situation's motion, capacity, or attainable goals.

This continues the partial-decision experiment. Each target keeps moving between passes. A poor first guess changes the actual state and may leave tension that subsequent passes must account for. Evaluation does not rewind the machine or silently clear the consequences of its actions.

What crosses the boundary

source context + retained useful pass
    -> captured preferred source option
    -> explicit source-option -> target-option correspondence
    -> target provisional preference
    -> target actions over a complete pass
    -> target-local discrepancy evaluation
    -> keep or revise the preference for the next pass

The source trains through the existing six-pass opposed-candidate experiment, using pass-level revision. Both inset and chevron construction families supply sources. The source's candidate identities remain distinct from the target's. Correspondence connects particular source and target options; their positions in an array do not establish that relation.

Export requires retained evidence that the selected option improved a complete pass or reached its goal. Merely copying the current preference cursor is not enough: after a failure that cursor may point to an option never yet tried. The export captures the option, source context and qualifying evidence rather than becoming a live reference to whatever the source prefers later.

The target receives a provisional starting preference through a visible correspondence. It does not install the source's evaluation history as its own pass memory, copy source actuator values or tension into its actuators, or inherit source motion-identification support. Its motion candidates begin unsupported, and its pass evaluations belong to its own context. The export still retains source evidence as provenance; the full connected archive is larger than the few fields used to choose the target's starting preference. A supplied correspondence may be mechanically readable and still be a bad analogy in practice.

Supplied comparisons

Each target is compared under three conditions:

  • Cold start: the original option order, with ordinary pass-level revision.
  • Transferred preference: start from the mapped source preference and allow the same pass-level revision.
  • Fixed transferred preference: start from the same mapped preference but retain it after readable outcomes. This separates the effect of reuse from the ability to recover when reuse is harmful.

All paired conditions start with equivalent target state and receive the same clock opportunities, observation rules and availability. Actual observations diverge as their actions change their worlds. Within each run, state continues across six passes of six beats. The host supplies the construction, candidate bank, correspondence and experimental perturbation. It must not consult a private correct answer to select a target action or revise the preference.

These are paired apparatus conditions, not independent samples of natural designs. Their role is to expose mechanisms and failures before drawing wider learning claims. No outcome is assumed in this protocol.

Structural safeguards

Source evidence, correspondence, imported preference and target evaluations must remain distinguishable in the native archive. A missing or ambiguous mapping does not select an arbitrary option. An imported preference cannot replace an outstanding choice in the middle of a pass. Current target admissibility still governs which responses can be used.

Later source adaptation must not rewrite a captured export. Later target adaptation must not alter the source's history or preference. Native transport must preserve the connected identities and correspondence within the restored world; equal coordinates or equal-looking words are insufficient substitutes.

Only a complete readable target evaluation can credit improvement, achievement, stall or regression. An unavailable comparison remains unresolved. The target retains two recent pass evaluations with explicit loss of older detail, as in the preceding experiment. A separate report may keep a longer history for inspection; the controller does not consult it.

This campaign uses pass-level revision to isolate preference transfer. It does not need to identify a unique motion explanation before acting. Utility may alter the next choice without eliminating a motion candidate, and a correct motion guess cannot create missing capacity.

What to inspect

Record the source option and its qualifying pass, the target correspondence, the imported target option, and any refused or unresolved import. For each target pass, expose the selected options, before/after discrepancies, accepted movement, remaining tension, available reads, retained candidates and preference changes. Compare first-pass damage and the first jointly settled pass as well as the final result.

A useful transfer should save effort relative to a cold start in at least some conditions. A harmful transfer should remain visible even if later passes recover. The fixed-preference comparison should help distinguish recovery from a target that would have settled regardless. A bounded run that does not settle must retain its remaining state and explanation rather than being scored as a hidden success.

Focused checks should cover evidence-qualified export, option-order independence, missing or ambiguous correspondence, source/target independence, import while a choice is pending, unavailable evaluation, recovery without reset, and native archive round trips. Representative complete traces should agree between native and compiled finite-law execution.

Limits of the claim

The machines, candidate banks, analogy correspondences and evaluation law are supplied. This can show learned preference reuse and revision through explicit structure. It does not yet show automatic discovery of a metaphor, discovery of new candidate machines, learned correspondence between unrelated domains, or structural growth. Those remain subsequent questions whose design should be informed by both useful and harmful transfers here.
