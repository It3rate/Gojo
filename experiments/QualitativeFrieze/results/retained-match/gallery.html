Gojo · pre-numeric pattern matching

Keep the match in view

Finding a path that answers a question is different from asking another question about the same path. These examples retain an actual match, then test what changes when its partners may—or may not—change.

The engine reads shared sites, ordered connections and qualitative directions. A site can be between two endpoints without specifying distances or equal subdivision. The pictures illustrate those structures; matching receives no pixels, screen positions or measured lengths.

1 · Find a match

A question identifies an actual occurrence, with bindings from pattern roles to participating sites and edges.

2 · Retain the context

Choose which roles must keep that occurrence and its internal site correspondence.

3 · Ask a follow-up

Compare an unrestricted search with a question about the retained participants.

4 · Recheck the condition

A later No can coexist with the original Yes: the questions ask different things.

Blue marks retained participation. It does not mean Yes, correct or preferred. All answers use the same text colour. Both pictures show the complete structure; the second highlights the selected roles. Solid copper dots mark actual shared sites; paired hollow purple dots keep coincident, unjoined sites separate.

Boundary and incomplete-read controls

Rebuilding a reader over the same observation preserves the retained context. A new observation needs its own correspondence. An unfinished read stays Open; a changed role contract remains visible.
