Machines for changing a read, a resolution, or a motion assumption

The simple picture

The construction has two controls, height and width. This pass gives them three ways to handle a difficulty: ask a different explicit question, try a supplied finer control, or test which of several motion descriptions fits an observed change. None of these silently replaces the original evidence.

1. Asking the alternative question

The section reader asks, “How far apart are these parallel sections where they overlap?” A zero section or disjoint intervals can make that question unreadable. The alternative asks, “How far apart are these two landmarks along the selected normal?” That can still be answered.

frame -> Closed(
  primary section-gap claim,
  (desired port -> (normal -> desired-tick/reach calibration))
    -> (hypothetical target role -> local construction capacity),
  endpoint claim,
  first-preference response law)

The target is constructed from the first landmark plus the desired normal displacement, in native shared-reach words. It is a hypothetical reference, not a physical vertex moved into place. The endpoint claim compares that reference with the second landmark. Both observations and their disagreements remain in the private witness; only response support crosses to the actuator.

Missing and ambiguous messages are applied to both alternatives. A hidden exact geometry read cannot sneak around a withheld observation. The displayed diagnostic can still know the separation; the receiver does not receive it.

2. Trying a finer rung

The reversal detector has a nine-row law over two ternary response domains. Opposed singleton signs can permit a finer trial only when the earlier packet was actually consumed, a nonzero step was accepted in the corresponding direction, and its after-state is still the current source state. Reusing an event or changing the earlier support under its old identity is refused.

Closed(
  coarse machine, fine machine,
  S(coarse,0,1) -> S(fine,0,3),
  local fine capacity,
  reversal reader,
  activation port,
  try-finer result -> (calibration -> fine extent port),
  attempt history)

The finer machine's unit is SubdivisionOf(coarse unit, 3). Its activation imports an observed coarse value through the displayed calibration into an independent state. Coarse pending tension, a nonempty fine target, insufficient capacity or stale evidence blocks activation and leaves a witness.

The original coarse value remains. A current coarse read of the fine value is another observation: for example seven fine ticks read as two whole coarse ticks with one fine tick left over. That read does not overwrite the retained coarse source. Its exact residue is not uncertainty about a missing digit.

In the viewer, all geometry uses the same common fine reach from the start. One coarse control tick contributes three reaches; one fine tick contributes one. A change of control resolution therefore cannot resize the object by a change of display scale.

3. Retaining evidence for a motion word

frame -> Closed(
  actual extent port,
  source tick span,
  landmark role,
  candidate positive-motion words)

trial = (candidate surface -> occurrence) -> Closed(
  extent port -> (captured before -> captured after),
  landmark role -> (before landmark port -> after landmark port),
  changed-input-port scope,
  actual transition cause)

For each candidate, repeat its word by the actual extent change and compare that predicted displacement with the observed native landmark displacement. The comparison retains its reduction and remainder. A mismatch contradicts that candidate under the selected trial premises.

Only a nonzero accepted change with an explicit single-input isolation premise can eliminate candidates. Zero change at capacity says nothing about motion. Changing both inputs leaves attribution unresolved. A missing word remains open. Two different words which reduce to the same displacement remain two possible structures, even when the drawing cannot distinguish them.

A unique surviving candidate must also have informative support before it can supply the later control's motion word. If later evidence contradicts every candidate, the result is an empty support with failure evidence; no rejected candidate is silently reinstated. Matching-event counts describe retained observations, not statistical confidence or independent evidence.

The experimental protocol supplies one positive trial per actuator/rung and the correspondence between its before/after landmark roles. These are honest premises of the test. The experiment learns within the supplied finite candidate scope; it does not discover arbitrary causal laws or choose where to put sensors.

How the three connect

candidate motion evidence -> selected motion correspondence
                                  |
section claim / landmark claim -> response preference -> pending gate
                                                        |
                           reversal evidence -> finer admission
                                                        |
                                      selected extent control
                                                        |
                           calibrated public construction read
                                                        |
                                          next observation

A finer actuator has its own tick and its own motion candidates. An effect observed per coarse tick is not automatically an effect per fine tick. The combined run therefore needs new trials after a rung activates.

These are reusable local structures, but the complete experiment is still supplied apparatus. The host schedules observations and trials, and the existing native readers reconstruct each path observation from role bindings. This pass does not add persistent material deformation, autonomous sensor placement, a general uncertainty solver, or an ornament taste model.
