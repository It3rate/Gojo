# Level-one primitive coverage

Audit for the first primitive-runtime checkpoint, 30 October 2026. This follows
all 22 rows of the [Level-one inventory](../../../GojoQuickDraw/docs/compact-structures.md).
It distinguishes existing native mechanisms from what this new compact execution
path actually implements. A related native fixture does not make a whole row
complete in the compact runtime.

The implemented compact fragment is deliberately narrow:

- [CompactArena](CompactArena.cs) captures only relations and placeholders, in
  four-word records. Addresses preserve ordered topology, aliases, slot identity
  and placeholder faces. Other element kinds are refused.
- [CompactTransitionPlan](CompactTransitionPlan.cs) derives finite atomic results
  and proof-row addresses from the existing native
  [finite-law reader](../QualitativeExecution/FiniteLaw.cs). It accepts at most 64
  participants per domain and requires the state and output to share the actual
  domain surface. It is a derived execution plan, not a universal instruction set.
- [CompactOccurrence](CompactOccurrence.cs) retains one mutable support and the
  current before/command/result/after receipt. Only a unique closed response
  through one supported row is applied. An open, ambiguous, contradictory or
  missing transition remains visible without choosing a path.
- [MotionDefinition](MotionDefinition.cs) supplies the carrier-free moving
  connection. [MotionCalibration](MotionCalibration.cs) is a separate optional
  native numeric observation; its carriers, points, projection and residue do
  not execute in the compact step loop.

These claims are exercised by the [compact runtime tests](../../Tests/PrimitiveRuntime.Tests/CompactRuntimeTests.cs)
and [motion tests](../../Tests/PrimitiveRuntime.Tests/MotionTests.cs). The native
sources linked below establish the relevant existing footholds; they do not
imply that those mechanisms have been compiled here.

## Boundary for the next extension

The common substrate is promising, but this checkpoint has not encoded Gojo
numbers into an executable carrier runtime. A numeric extension still needs
carrier identity and opposed faces, shared tick references, immutable unit
promises, signed locations, unsigned value with signed tension, attachment
ownership, and the selected settlement law. Its transfer and remainder contract
must be tested directly, rather than borrowed from the finite support guard.

Definition edits are another explicit boundary. The arena is a frozen snapshot;
steps execute it without scanning mutable native objects. `ValidateSource`
detects disagreement with the captured source and marks the plan stale; a fresh
capture is required to adopt edits. This is not automatic local dependency
invalidation or topology discovery. The reference graph, correspondence maps,
optional native reconstruction and optional numeric observer remain additional
costs outside the compact payload and must remain visible in measurements.
