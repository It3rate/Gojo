# Minds experiment discipline

The repository's canonical Gojo prompt still applies. Read
`docs/ExperimentReadiness.md` before designing an experiment here.

September 15 priorities: start small and observe. Declared external numeric
interfaces, including decimal calculations and sensor conversions, are allowed.
Compiler guards and exact replay are future tools, not prerequisites. Variation
between runs is evidence to investigate, not automatically an invalid run.
Settlement is relative to a goal and an observer's scale; ending an observation
window is not the same as the living system stopping. Build broader observers
as Gojo reads where practical, retaining finer activity and unresolved work.
External controls remain useful checks. Unexpected valid behavior should invite
closer observation. Full preregistration is an advanced mode; exploratory runs
need a clear description of their selected rules and any changes.

- Distinguish kernel conformance, experiment validity, and the scientific
  outcome. A valid negative result is not a test failure to fix.
- Keep participant meaning in connected Gojo structure. Host records may own
  run identifiers, hashes, schedules, and reporting, not hidden participant
  goals, beliefs, or learning rules.
- Declare the host's information, choices, and policies. Do not let reference
  answers, future observations, or evaluator scores guide participant actions
  unless that feedback is an explicit experimental input.
- Freeze a versioned protocol and its numeric dependency boundary before
  confirmatory runs. Exploratory changes are welcome, but label them and retain
  their results; test revised claims on unused cases.
- A missing operation is a missing operation. Preserve its unresolved state or
  develop a generally justified Gojo mechanism with independent conformance
  tests. An explicitly identified external adapter may calculate outside Gojo;
  preserve its input/output contract rather than disguising it as a kernel law.
- Exact integer arithmetic implementing a justified Gojo reader is allowed.
  A calculation is not grounded in Gojo merely because its answer is later
  placed in a carrier. Rendering, reference models, and evaluation are separate
  numeric boundaries.
- Never silently change update order, thresholds, candidate sets, budgets,
  measurements, or exclusions after observing an inconvenient result.
- Report stalls, oscillation, limits, missing observations, invalid runs, and
  unfavorable comparisons as well as successful outcomes.
- Reuse existing fixtures and graph transport. Add no parallel number system,
  universal uncertainty score, or global controller presented as local behavior.
