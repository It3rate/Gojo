Existing predictions include the base structure's internal timing connections. Shadow gains alone are not exported improvements. A tie can mean the existing structure already predicted the turn. Magnitude error deliberately ignores direction; an inverted prediction may preserve scale. Charged examinations count shadow opportunities after recruitment, not every published event. Each costs one supplied utility tick, not measured runtime or conserved input energy.

A fresh packet from a lagging physical process is graded normally. Missing publications remain open and earn neither event reward nor event cost. The demand-pause condition requests no event-assisted output during arrivals 81–160, then restores demand.

The CSV records connection presence after assessment separately from event use in the issued forecast. Demand can disable export before the connection withdraws. The three leading-regular rows repeat the same deterministic control; they are not independent trials.

Dropouts suppress delivery, while the producer continues observing. Switching to the lagging process introduces one held source level as that delay begins. The reversal predicate and reversal response are supplied structures; these trials do not discover either family.
