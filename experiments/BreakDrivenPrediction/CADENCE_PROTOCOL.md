# Cadence applicability independent of demand: fixed protocol

This exploratory pass separates a remembered interval hypothesis from evidence
that its current continuation still applies. Written before implementation and
trials. The preceding attentive learner and its saved results remain unchanged.

## Connected shape

```text
scoped learner = prior attentive learner parts + cadence scope
scope = group(public port, allowed timing slack span,
              fresh two-site trace, remembered candidate or open slot,
              active continuation or open slot,
              copied availability, latest local assessment)
candidate = group(two frozen event grounds, interval equation, interval read)
continuation = group(candidate, expected next coordinate,
                     closed allowed window, arithmetic/read evidence)
```

The learner and scope share the exact fresh-trace relation and availability
site; they do not own duplicated authoritative samples. Candidate/window meaning
is traversable through its native grounds, equations, claims and witnesses.
Remembering a candidate does not assert an applicable phase. The current packet's
bounded steps replace the preceding assessment; no root-history chain is kept.

The fixed allowance is two public clock ticks on each side of the next expected
event. It is a supplied acceptance policy, not a measurement error estimate,
confidence interval or the consumer's requested resolution. From fresh events
`a,b`, native arithmetic forms `period = b-a`, `expected = b+period` and the closed
window `[expected-2, expected+2]`. The allowance stays fixed across all trials.

## Local admission law

Grade any outstanding exported promise first, through its frozen demanded rung.
It remains accountable even if the new scope read breaks continuation. Then
process each event in a complete public batch in chronological order:

1. If an active window exists, compare the arriving coordinate to both bounds
   before incorporating it into the trace.
2. An event outside the window breaks that continuation. Open the fresh trace,
   retain the old candidate for inspection, and use this event as the first
   fresh ground. Two fresh events are required to ground a replacement.
3. A fitting event updates the local interval hypothesis using the last two
   fresh events. With no window yet, the next event can supply the second ground.
4. After the events, complete coverage to availability with no further event
   opens continuation when it reaches the inclusive upper deadline. Preserve
   the remembered candidate and a native absence witness; clear the fresh trace.

Within-batch comparisons are retrospective consistency checks, not prospective
forecast successes. They earn no support. They still make causal local structure
inspectable. Only a forecast issued before later input can receive utility credit.

Unknown or partial coverage opens phase and fresh trace without asserting
absence, while retaining the candidate. No delivered observation means no
transition. The existing conservative contract does not learn even known partial
events from an incomplete batch. The source's endpoint is not reinterpreted as
proof of flatness. An empty reversal collection can also describe monotonic input.

These local checks run independently of output demand and accumulated support.
The remembered candidate is not erased by a failed applicability read. In scoped
mode this mechanism owns trace qualification; attention wake does not separately
clear an otherwise qualified trace. Prior attentive mode keeps its existing law.
All physical cursor/support/attention changes still share one whole-arrival
settlement after staging; scope construction itself is a pure structural read.

New exports require an active continuation whose expected center is strictly
after current availability, plus the existing demand/attention gates. If the
center has passed but its allowance window is still open, wait. Do not use the
old quotient to leap over an unresolved cycle. Existing promises are never
retroactively replaced. Unknown scope reads remain inspectable and cannot earn
success, manufacture a zero interval, or silently clear source information.

## Fixed challenges

Compare the new scoped reader with the existing attentive reader on identical
public packets, separate control carriers, and the same 1/3/12 timing ladder.
Use 720 fine acquisitions with twelve-tick reports, probe cadence four issues,
and seeds 113, 907, 2029. Only jitter depends on the seed; deterministic repeated
rows are not independent evidence. Never expose generator labels or future data
to either learner.

Demand is width 3 through tick 240, zero at 241-360, width 12 at 361-480, width 1
at 481-600, and width 3 at 601-720. Apply demand before report consumption.

- Regular five-tick alternating runs.
- Jitter: independently supplied run lengths from four through six ticks.
- Restart: five-tick runs through 180, flat through 360, eight-tick runs through
  540, then four-tick runs. Restart a positive run at 361 and 541.
- Doubling: five-tick runs through 240, ten through 480, twenty through 720;
  restart a positive run at each phase boundary. This challenges legitimate
  cadence changes, including a change during output withdrawal.
- Long period: twenty-tick runs throughout, with many complete empty reports.
- Alternating intervals: run lengths five and thirteen, repeating. This is
  predictable composite structure that a last-interval model cannot express.
- Unknown coverage: regular five-tick runs, with public event collections and
  coverage evidence made open for reports 252 through 300 inclusive. Preserve
  port, span, timestamp and endpoint; both learners receive the same masked
  packet. Later complete input can ground a fresh trace, not fill the hidden gap.

Count issued/wanted/settled forecasts by frozen width, prospective hits/misses,
absence misses, unknown outcomes, and omitted matching/mismatching reference
predictions. Record native scope window breaks, absence breaks and unknown opens
separately from predictive scores. Record remembered-candidate presence and
active-continuation presence separately. A missing new forecast is not a correct
prediction of absence. Track first post-boundary issue and its target coordinate.

Measure issue/assessment cell counts, same-thread managed allocations around
each learner admission (including startup calls, excluding learner construction,
source/demand/report/graph work), and reachable graph sizes every 120 ticks.
Fixed call order and no warmup exclusion make allocation a diagnostic, not a
runtime benchmark. The extra continuity checks have a real cost, including
during demand zero. Acquisition remains fixed and is not an optimization result.

## Verification and interpretation

Test native expected/window boundaries, same-batch late events before learning,
complete absence independent of demand/support, unknown versus observed absence,
candidate retention, two-fresh-event restart, a still-open past-center window,
no duplicate reward, pending-promise preservation, carrier identity, shared
trace/cursor aliases, stale-root rejection, pure reads, checkpoint continuation,
and bounded evidence. Keep earlier experiment tests passing.

This is a supplied applicability policy, not discovered change detection. A real
longer period can violate the old window without being erroneous. Requiring new
grounds may discard useful anticipation. A lone fresh ground cannot itself
establish which interval should follow. Alternating and hierarchical patterns
remain challenges for composition rather than cases to patch by name. Do not
tune the allowance or reinterpret withheld predictions as successes after seeing
the measurements.
