# Composite learning study

Status: complete. Implementation, three exploratory pilots, the frozen eight-seed
confirmation, independent review and the full repository test gate are finished.
The confirmation produced 904 result rows and 1,185,792 evaluation trials. See
[REPORT.md](REPORT.md) for results and limitations and [SUMMARY.md](SUMMARY.md)
for the short version. The protocol below records the settings frozen before
confirmation launch.

## Objective

Test whether a learned native relation becomes a reusable service for another
learner, supporting a capability unavailable through an isolated primitive's
advertised observations. This is an operational capability claim, not a claim
about consciousness, subjective comprehension, general intelligence or creation
of arbitrary mathematics.

## Work sequence

1. Write native shapes and strict publication boundaries. Keep world state and
   evaluation labels separate from learner inputs.
2. Learn a predictive relation from temporally separated direction publications.
   Start with single-source candidates and expand a bounded generic arithmetic
   grammar only after inadequate primitive predictions.
3. Freeze the retained relation and train independent task consumers through its
   coarse port. Compare reuse to newly learned and broken services, and to a flat
   learner receiving the same public sensor information.
4. Learn paid refresh versus reuse in a persistent apparatus whose rule changes
   without a mode-change announcement. Include outcome-memory and always/never
   probe baselines.
5. Run pilots, retain their failures and adjustments, then freeze source and
   settings for fresh confirmation. Use paired seeds as replicates.
6. Verify port restrictions, native transport, frozen parameter guards and
   important unresolved cases; run the repository solution test gate.
7. Produce a complete report, reproducible raw results, native archives and an
   offline visual inspection page.

## Success and failure must both remain visible

A reward advantage alone is insufficient. Seek a retained native intermediate
relation, meaningful publication intervention, reuse in a new consumer, and
recovery after unannounced changes. A bounded supplied grammar can discover a
useful composition without establishing unrestricted syntax or hierarchy
discovery. Negative controls may expose information loss, distribution change,
insufficient data or an authored admission law; identify which occurred.

## Provisional world

The private apparatus rule is a direction `h` chosen from `-1,+1`. A fair input
pulse `a` is followed later by response `b=a*h`. The two primitives each see one
direction stream. Either entire stream, by itself, has the same distribution
under both rules. Neither receives the other signal, chosen task action,
global consequence or the private rule. The composite can join their public
events and receive independent action consequences through explicit routes.

Discovery trials use fresh balanced rules to prevent outcome history from
substituting for the joint observation. Subsequent closed-loop blocks retain
the rule and switch without announcing the boundary. Command/resource outcome
history can be informative in that later task, so a dedicated memory baseline
must quantify that alternative route.

The world defines pulse/response laws, goals, costs and consequences. It does
not write learner memory. Shared timing or event identity is an authored
interface, not evidence that pairing itself emerged.

## Controls planned

Isolated A/B, no learning, shuffled outcome feedback, absent communication,
communication independently shuffled while preserving each stream, erased
sample memory, previous-trial pairing, fixed aggregation, equal-budget flat
learner, always/never probe, last-outcome memory, and state-port intervention.
Held-out tests vary delays, signal orientation, missing observations, task
wiring and switching frequency. Training and frozen evaluation are separate;
operational state may continue evolving during frozen evaluation.

Confirmation settings and any pilot-driven changes will be recorded before
fresh confirmation starts. No paid Jev calls are required for the primary study.

## Pilot record and frozen confirmation protocol

Frozen on 2026-10-11, after pilot seed identities 0..4, before observing seeds
200..207. All pilots remain in `results/pilot-01`, `pilot-02`, `pilot-03`.

- Pilot 01: one seed, 320 discovery /96 consumer /128 evaluation episodes,
  384 manager-training /256 temporal-test episodes, probe price1. Confirmed
  learned relation and publication intervention; manager training too short.
- Pilot 02: two seeds, 384 discovery /192 consumer /256 evaluation,
  2,048 manager-training /768 temporal-test, price1. Both history conditions
  largely learned to probe always. The immediate reuse advantage at hazard.04
  is only .2 resource units and noisy under finite count64 evidence.
- Pilot 03: two seeds, same budgets as pilot02, price2. Both immediate-history
  policies mostly reused and refreshed after failures. Delayed-history policies
  differed between seeds. No learning-law or age-bucket changes were made.
- Transport checks were strengthened after pilot02 from shape checks to actual
  feature/prediction/action/query replay. Connected pipeline archives preserve
  shared axes and mutable sites. Earlier pilots retain their original checks.

Confirmation: eight fresh seeds200..207; discovery768; consumer192;
evaluation768; manager-training2,048; temporal-test2,048; hazard.04; price2.
Frozen lower parameters and consumers, immediate versus five-step operational
outcome history, also hazard.12, price5, missing-signal probability.10.
Manager utility credit during training remains immediate in both history arms.
Native model C# sources and these settings are hashed in each run manifest.

Primary checks: learned held-out joint prediction; consumer success through
the opaque service; same-state and opposite-state interventions; fresh-consumer
transfer curve versus flat and newly trained lower service; paid probe/reuse
return versus always-probe and outcome-memory. All controls and seeds are
retained. Paired seed differences receive 95% Student-t intervals, interpreted
descriptively without multiple-comparison correction. First success after a
switch is reported separately from sustained recovery, which is not measured.

No changes based on confirmation outcomes are allowed within confirmation01.
Any later repair or new experiment must receive a separate directory and an
explicit explanation; partial and failed run artifacts remain preserved.
