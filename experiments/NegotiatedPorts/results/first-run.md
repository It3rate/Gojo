# Negotiated live ports: first fixed results

Protocol `caf8cae` preceded these results. No price, cost, admission or feedback parameter was tuned after seeing trial behavior. Native structures calculate forecasts, interpretation, error, signed service value, comparisons and drained resource transfers. The host supplies wiring, contact/renewal policy, admission order and report aggregation.

Focused checks: 16 passed. Detailed observer replays are in the four trial JSON files; only selected full native witnesses and final worlds were saved.

The resource prices are supplied accounting costs, not measured execution time. Operational source equations and physical publication relations persist, but current claims, transfer witnesses and financial arithmetic evidence are constructed on admissions. Cumulative allocation is not retained memory.

Pure inspectors may calculate a diagnostic forecast without spending or updating its live port. Only paid service updates a current exposed live port. The fee accounts for this supplied admission policy, not every CPU instruction.

A price fit or paid contact is not a delivered forecast. An evaluated zero/no-service baseline is not an evaluated paid service. Frame records separate current issues from prior issue outcomes and preserve missing outcomes as unresolved. Generated displays must not infer successful service from attachment alone; inspect gate and paid/current port presence.

Population, exposed recipe family, cyclic neighbor traversal and four-service exploration cadence are supplied. There is no autonomous port invention, reproduction, general coarsening, strategic price increase or global optimality claim. No per-arrival rent is charged to dormant recipes; fixed occupancy is the present retention bound.

The summary JSON contains the exact run counters, native conservation results, retained graph sizes and allocation. Direction-to-fine service uses the exposed one-direction-packet to one-source-tick proxy. It does not claim a direction packet establishes exact source magnitude.
