# Returning keys and through-stems

A drawing can have many right angles while reading as a ladder. A cluster of lines can look like a fork even though its pen histories never join. This local follow-up learns with stricter construction witnesses. Its first brief asks the pen to return through a continuous run of right-angle corners. Its second asks for a real side arm on a continuing main path. The original judges still read the same diagrams independently and the machines still run from their packed Gojo bytes.

The [registered protocol](Protocol.md) sets the three training arms, matched budgets and twelve predictions. Strong cells and history utility measure related aspects of the same evidence. The study does not measure independent human preference.

## Run and inspect

The project prefers the archived original path runtime in `artifacts/local-path-ornament/runtime-v1` and otherwise builds against the source project. The registration verifies the exact original assembly fingerprint. Run commands from the repository root, using a new directory to reproduce the competition.

~~~powershell
dotnet build experiments/OrnamentPathRefinement -c Release
$runner='experiments/OrnamentPathRefinement/bin/Release/net10.0/OrnamentPathRefinement.dll'
$run='artifacts/local-path-ornament/shape-refinement'
dotnet $runner verify $run
~~~

For a new experiment, run `freeze RUN` and `train RUN 5`. This preserves every proposed program and the parents which generated it, including failures. Each completed island has a ledger fingerprint and can be resumed. `assay RUN RELEASE.json` verifies the common release and all finalists before running the reserved samples; independent execution of a winner needs only its bytes and original path runtime. `python experiments/OrnamentPathRefinement/Gallery.py RUN` renders the stored material edges.

The recorded design ID is `6C05DC9CE4AA116B4C0FF3CFE3D852730C80ABC5C5277C687F2EA98B6E8E6E38`. All 24 finalists were locked under `1DB495541580BC6CDD4F454339804BD689BA13B3441E4EE8B0BBD7F70ADA95AF` after 98,304 proposals and 393,216 training drawings. Each of six calibration challenges gave its intended result. For example, rearranging the drawing order of the exact same segments took key utility from 1 to 0; disrupting the stem's owner identity while keeping the same ink and joint position took spray utility from 1 to 0.

## Reserve result

Across 576 finalist executions, the blend raised returning-key history utility from 0.000 to 0.910 and spray utility from 0.205 to 0.897. Both blended sets had strong witnesses in 91.7% of bays. Original utility fell from 0.936 to 0.890 for keys and from 0.827 to 0.753 for sprays. Nine predictions were supported, one inconclusive and both predicted original-score equivalences were contrary.

The most informative failure is visible in the registered comparison. A key winner goes west, north, east and south back to its starting position, then advances. It qualifies under the registered continuous-turn law and looks like a box on a rail. After the reserve results we replayed all 288 key cases and required each otherwise qualifying interval to avoid revisiting an XY position, including segment interiors. The audit reproduced every original strong-bay fraction exactly. **No program in any arm produced even one strong open bay on this stricter reading.** A topologically valid return, an open meander, and a visually preferred border have different evidence.
