# Gojo.Encoding

`Gojo.Encoding` is the experimental encoding layer for Gojo structures and
concept addresses. It does not own Gojo meaning. It builds small relation-shaped
surfaces that can later be saved, read, merged, generated by models, or lowered
into compact integer packet formats.

Current footholds:

- `EncodedTextSurface` stores Unicode text as ordered integer code points and
  exposes UTF-8 integer helpers for binary-oriented packets.
- `ConceptAddressSurface` builds variable-length semantic addresses from atoms,
  compound parts, context, and residue/tension.

The intended split is:

```text
local packet id
  stable reference inside one file or bundle

semantic address
  variable-length Gojo structure with provenance-like concept hints

learned vector
  optional derived read, not the source of meaning
```

The first examples are intentionally tiny. Larger ECAD and documentary bundle
formats should consume this layer only when the small surfaces prove useful.
