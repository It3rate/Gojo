A useful gap is not an error

A bolt must fit through a hole. We want a little room between them. Equality of their diameters would be the wrong target for this example.

What is checked, and where this example stops

The observed clearance is [0.10,0.30] mm. Distance from the broad allowed interval is exactly zero; the narrower specification leaves possible violation [0,0.05] mm.

These dimensions are illustrative, not a fastener standard. Treating a tolerance as an actual-value bound requires a conformance premise.
