A position needs a frame

A slider controls a position along a rail from 10 to 210. Its local parameter runs from 0 to 100. The parameter and the rail use different scales.

What is checked, and where this example stops

The kernel projects both parameter samples into the rail basis and verifies that coarsening 47 retains seven parameter ticks.

The frame defines parameter position. It does not make that parameter an arc-length measurement on an arbitrary curve.
