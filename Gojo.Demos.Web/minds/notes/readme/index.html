Minds

Start with the chronological experiment overview for the completed studies across both Minds/ and experiments/, their results and conclusions. It distinguishes this notebook's recorded experiments from the proposed roadmap and the later research.

The public notebook is at gojo.inklingai.ca/minds. The experiment roadmap places the work needed immediately before each proposed experiment. It is the current suggested sequence; the readiness review below retains the wider audit backlog.

Minds runs small experiments with connected Gojo systems and makes their behavior visible. Its first example is two local estimators exchanging views.

The retained runs below were recorded in September 2026. They are preserved experimental records, separate from later projects under experiments/. Checking the runner against the current kernel does not replace those records; use a new output directory for a new run.

Experiment 03 now tests predictions issued before observations arrive. Read the findings or open the prediction viewer. The fixed line rule wins on ramps and loses to hold-last on the alternating and step sequences. Missing outcomes remain unscored. All twelve cases match the independent exact calculation; this is parameter fitting, not learned model selection.

dotnet run --project Minds -- --experiment3

This writes a new directory under Minds/results/predictions, including the protocol and tapes captured before execution, before/after event journals, all outcomes, the exact reference and the viewer. An optional second argument chooses an empty directory. results/predictions/publication.json explicitly selects which captured run is published. Existing captures are not overwritten.

Experiment 02 has now run 24 feedback conditions in three fresh worlds each. Read the findings or open the feedback-limits viewer. All 72 runs matched the independent exact reference at the recorded events and round observations. This checks the selected contract, not an advantage over conventional arithmetic.

dotnet run --project Minds -- --experiment2

This writes a new timestamped directory under Minds/results/feedback-limits. An optional second argument chooses an empty output directory. Each run retains both implementations, the case parameters and event tape. Publication uses the explicitly selected directory in results/feedback-limits/publication.json; it does not silently switch to the newest run. The selected rules were written before evaluation.

What runs

Five fresh instances of the existing two-space fixture explore half, full and quarter responses, a different message schedule, and a selected response to local reference observations. The driver uses the existing Gojo calibration, publication, receipt and response readers. It imports the existing authored fixture through Gojo.Encoding; participant meaning remains in Gojo structure.

The observer is also built from Gojo reads. It retains each estimate, their average, disagreement, local changes, total movement and reference mismatch. The average can remain unchanged while the parts move. Observations and action evidence are connected through a Gojo timeline. The browser displays those captured results, with a choice of paired rounds or individual events.

These are exploratory observations, not learned response policies or a claim that the system permanently stops when the observation window ends. Movement measures change in estimates, not physical energy. Automatic idling, learned selection of responses and crystallization into a replacement equation remain future work.

Current priorities

Observe first. External decimal calculations are acceptable through declared interfaces. Exact replay and compiler-level numeric guards are useful future tools. Different results are a reason to inspect the conditions, not automatically a failed experiment. Keep external inputs, authored policy and actual participant responses distinguishable, and preserve surprising outcomes.

The readiness review retains the broader research backlog with these priorities applied. The protocol template is available for later confirmatory work.

Minds -> Gojo.Encoding -> Gojo, with a direct Gojo reference for structural observations. Gojo does not depend on Minds. No kernel semantics are changed by this experiment. Decimal conversion in the report is a one-way display adapter.
