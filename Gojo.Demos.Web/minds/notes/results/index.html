Movement is abs(change in A) + abs(change in B), a measured change in estimates, not physical energy or CPU work. The plot also exposes the temporary changes between the two applications.

The local reference values both read as 2 in the comparison unit. Reference mismatches remain available even while peer mismatch is zero. The reference condition deliberately selects those existing observations in round 3; it does not discover that selection.

Response, comparison, receipt, and application use existing LocalCalibration readers. Average, mismatch and movement use BoundedQuantity observations and calibrated composition. The host selects schedules and response fractions. The browser only displays captured results.

Retained fractional requests are plan residue; they are not automatically carrier tension. Unknown source reliability remains unknown. Automatic idling, response-policy discovery, and replacement by a learned equation are future work.
