[normal] Everything that can be done with a segment on a line
[normal] A line is like a path that can extend in each direction. A line has a width, but we are only considering the 1D aspect of it, so any width, height, or other surroundings are ignored. Lines have two directions, and we can choose one to be forward and the other backwards.
[normal] A trait can always be represented by a line. Traits are properties that have magnitudes ordered from lowest to highest in a linear progression. Once calibrated, the line represents the lowest and highest known values for the trait. If values are discovered beyond the limits of the line, it can be extended or made more precise.
[normal] This line does not have to be straight. We are only considering one dimension, but it could be a curvy line, the edges of a polygon, a satellite's orbit, or a path through the woods. The shape of this line is significant when it represents repetition or symmetries.
[normal] A focal segment is a segment of any achievable length on this line. The segment has a start point, and end point, so it can point forward or backwards. Note that points are also segments, just they are the width of the smallest possible resolution.
[normal] A line with segments on it represents everything that can happen in one dimension. Because this is such a fundamental object, we will try to exhaustively enumerate all the unique operations that can be done with it.
[normal] Select
[normal] This can be done choosing an existing segment, or creating a new one. Creating a new segment can be done manually or algorithmically. The segment represents what has been selected.
[normal] Direction
[normal] Every trait has a linear progression of magnitudes, and every segment has a start point and end point. This means the segments have information about which direction they are pointing - low to high, high to low, or can’t tell (a point). Note this has nothing to do with how the trait line is drawn - the line could be vertical or circular. It is better to imagine the line going from red to blue, with the segment’s end point either redder or bluer than the start point. Neither red nor blue represent forward - that is defined elsewhere.
[normal] Repeat
[normal] Whatever we do, we can do again. If we select something, we can select a second thing. And a third. The same goes for any actions we do. Geometrically, repetition can be represented by multiple segments on a line, a line that joins onto itself (like a polygon or circle), or going back and forth along segments. Repetition is the second fundamental action in math, after selection. All patterns, and therefore all predictions are based on forms of repetition. In normal math, repetition is (in a very limited way) expressed using exponents.
[normal] Repetition implies steps done in order. This brings in the new dimension of time. Everything in the universe is in constant motion, so all things naturally exist in the time dimension.
[normal] Count
[normal] Being able to create more than one segment (using repetition) results in being able to count. Segments do not have to be the same length to count them - each segment acts as its own unit. We count segments without regard to length (half a segment is still a segment). This means we can only count whole numbers at this point.
[normal] The only 'natural' counting order is when the number of elements change over time. This is because time has a single fixed direction causing events in sequence. If we see a number of elements all at once, we must impose a counting system on them. Without a system, we can't keep track of what is already counted and what isn't.
[normal] With the tools so far, counting has to be addition by one (1+1+1+1=4). The ability to separate elements into groups while counting is important though. It bootstraps the idea of merging more than one element at a time into a total, also known as addition.
[normal] Addition
[normal] Addition of segments is the joining of two groups that have already been counted. In normal math, we think of whole number addition as the algorithm we preform in order to not have to recount everything. These are great skills to know, and probably among the most important inventions we’ve ever made. But it is important to remember that addition is really the joining of two groups of elements that we are able to count. There are a lot more decisions involved in joining two groups than adding two numbers, and they are all important at different times.
[normal] Sometimes when we add to an ordered set, we care more about the resulting set than the total. For example adding C,E to A,B,D we might expect A,B,C,D,E rather than ((C,E),(A,B,D)). Or we might want to copy the second set into the first, keeping the original. We might have counted each set differently, so need to clarify how the result should be ordered. We may want to ignore duplicates. All of this falls under addition.
[normal] When combining two groups into one, we gain clarification by filtering information that isn’t relevant to our task. This is a choice, and what is useful is context sensitive. As always, there are insights to be had whenever we notice we are making a choice, so it is important to keep a broad view of what something as fundamental as addition actually represents.
[normal] Note that with all this information so far, we still can’t count backwards or subtract.
[normal] Subtraction
[normal] At its most basic, subtraction is removing from a selection. If it is an ordered selection we are removing from, we traditionally remove from the ‘end’, or remove randomly and reinterpret the results. If we add 4 oranges to a bag (1,2,3,4), and then remove one, the remaining oranges could be (1,3,4). We usually consider oranges in a bag to be unordered, so we would either reinterpret the removed orange to be the fourth one resulting in (1,2,3), or reinterpret the oranges (1,3,4) to be (1,2,3). We would call this a bag of three oranges when focused on the unordered total, but if asked to count them we would have no trouble pointing to a first, second and third, in some order.
[normal] This may seem like hair splitting, but there are certainly cases where sets of things are ordered, and we want to delete a certain member. In these situations (1,3,4) is not the same as (1,2,3). It is important to keep a broad view of what subtraction actually is, or it will be hard to understand it in less intuitive situations. Subtraction is the removal of specified elements from a group. How elements are specified can be as important as how many are specified.
[normal] With ordered counts (like discrete numbers), it is tempting to define subtraction as just counting backwards, but that wouldn’t cover cases where you subtract one group’s count from another’s. Counting backwards with a one to one correspondence is closer, but we still need to define what ‘backwards’ means here. If we used a heuristic for ordered counting (like say smallest to largest) then we can reverse it (largest to smallest). One can imagine ways of subtracting by counting backwards with this set, but there are many other ways to get a one to one correspondence with set elements.
[normal] Corresponding elements can always have multiple interpretations here as there are multiple ways of defining how things should correspond. Traditionally this is just one to one for each element in its given order. But as with addition, there are many branches of mathematics where the identity of each element in a calculation matters more than its result. We also can run into a problem this correspondence method - we sometimes want to subtract more elements than exist in the target set.
[normal] Negatives
[normal] We can now add and subtract groups of segments using correspondence, however there is an unresolved problem when we try to subtract more elements than exist in the original set. There are two ways to think about these negative numbers. The first is they are selections that have been made, but not yet fulfilled. The second is they are positive selections, but of an opposite thing. For example a person could have ‘negative ten dollars’ or have ‘positive ten dollars of debt’. These are not two ways of saying the same thing.
[normal] The ‘negative operation’ mirrors a value at zero, so 5 dollars becomes -5 dollars. Adding 1 dollar here will still make you richer. This is what negative means.
[normal] The ‘debt operation’ mirrors the whole perspective of that +1 means without changing any values. The value is still 5, but it is of debt instead of credit. Adding 1 dollar (of debt) makes you poorer.
[normal] Negation is the operation that mirrors values. A negative number is mirrored around zero, and subtraction is addition of such a negative number. For example 5-3 is 5 plus three mirrored around zero (-3). Negation is not the second option, the one that mirrors the number line itself. More on this crucial point later.
[normal] Unit
[normal] Once a segment is selected, it can be used as a unit. So far have been using every segment as its own unit, which is how we can count them. As noted, these units do not have to be the same length. These types of units are very common, we do not expect three dogs to have the same weight, and we know three months does not mean each contains the same amount of days. This makes precise comparisons impossible - we have no way of dividing units, and we can’t say a single unit 1/3 is the length of three other units with any confidence.
[normal] What we are sure of is each unit (segment) has a start point and an end point. Traversing these, there is no unit at the start, and there is one unit by the end. Numerically this means the start point is zero, and the end point is one. The other number we can imagine here is -1. Negative one uses the same unit, but with the end point (1) mirrored around the start point (0). Again we don’t know anything about the true length of this negative segment (it could be millimeters or it could be miles), just it is the same length as the original segment. For both +1 and -1 the unit is pointing in the same positive direction. Think about what it would mean to have a negative unit.
[normal] Compare
[normal] Every segment is its own unit, but to compare things we need a calibration unit. There is no ‘correct’ calibration unit - comparisons are always relative, and any segment can be compared with any other. With addition and and a calibration unit we can now produce fractions. For example we could add the calibration unit to itself 5 times to form segment A, and then make segment B by adding the calibration unit to itself 60 times. We can now compare A to B because they use the same units, The first segments is 5:60 the length of the second, or 1/12th.
[normal] If we are given a segment of arbitrary length, we can find its ratio to the calibration segment using similar strategies. For example we could add copies of the shorter of the two until is it longer segment, then add copies the other segment until it is the longer one. Eventually the two segments will be the same length, to whatever level of precision measured. The ratio will be the number of calibration units to the number or arbitrary segment units.
[normal] Note that if we change the calibration unit to be the second segment, the only thing that changes is the order of the ration. So 5:60 (1/12th) would become 60:5 (12). This is the reciprocal, which is the neutralizing operation for a comparison. Anytime something is 12 time larger, something else is 12 time smaller. Like select and unselect, add and subtract, or negative and positive, comparisons have an ‘anti-comparison’. Every operation has a neutralizing operation, because energy is always conserved.
[normal] Jump and Slide
[normal] A point on a line can only be selected, unselected, or moved. Selecting multiple times is duplicating or counting up, while deselecting multiple times is deleting or counting down. Addition and subtraction encode selecting and deselecting. Moving a selection is a continuous operation, the equivalent of sliding. We can move the whole segment along the line, or just move the start or end point. Any motion will change the position of a segment, and changing an end point will also change the length. All motion is encoded with multiplication (including it’s reciprocal, division). Multiple moves are encoded with powers, which we will address later.
[normal] We can imagine a move to be a jump or a slide, which represent discrete or continuous motion. When looking closer though, a ‘jump’ move tends to be a continuous one that we ignore the middle part, or a new selection. It is useful to remember that at the limit of our resolution, continuous motion appears as a series of discrete steps. Conversely, every discrete distance can be traversed with a continuous motion. We can only be certain an operation is discrete if there is a known location between the start and end of a move, and the motion does not pass through it. We know 5 exists between 3 and 8, so if we move from 3 to 8 and don’t pass through 5, we know at least some part of the move was a discrete jump. This type of jump can only happen with selection, which means it can only happen with addition. For a real world example of such a jump, imagine selecting a six pack of juice boxes, then changing your mind and selecting a 24 pack. At no point were there 7 or 8 juice boxes selected, so this would be a jump, and therefore addition. We subtracted 6 and added 24. We did not multiply 6 by 4 because the transition wasn’t continuous.
[normal] When sliding segments or points we move through all the positions between the start and end positions. Imagine a segment from 0 to 2, and we slide it’s endpoint to 4. It is now twice as long, so we have multiplied (scaled) it by two. Note that we still have one segment, and it is still the same segment. In addition we start with the same segment of length 2, but then add a second segment of length 2. We can select both as a new single selection (we are assuming we place them tip to tail here), and have a segment of length 4. This is a new selection that was created from two selections. This is very different than stretching a segment, and the difference is crucial.
[normal] When selecting, we can select nothing, so zero is a valid value. When stretching, we need to stretch a selection, so the operation does nothing if nothing is selected. Conversely if a segment is selected and we stretch it to ‘zero’, it is still a segment. We can no longer say how long it is (it is by definition beyond our ability to measure), but we know it is there, and we know it has a start and end point. We also know if we stretch it larger it will eventually come back. If it was a series of segments that formed dashes, they will come back as the same dashes. Sliding elements never destroys them, which is why we can move and endpoint from +5 to -5 (through zero) and not have our segment disappear forever.
[normal] The other difference with selection and motion (addition and multiplication) is a selection does not need to be of the same elements. We started by selecting segments of different lengths, but we could even select segments of different lines (remember, lines are traits), or segments on completely different objects. It feels natural to select (add) 4 apples and 3 oranges, but it is less obvious how we would multiply 4 apples by 3 oranges. More on this later.
[normal] Geometric Interpretation
[normal] In the real world the segments we measure (property ranges) on paths (traits) aren’t usually lined up neat and straight. In spite of that, it’s still useful to have a clear and simple geometric interpretation. For the next few sections we’ll build this interpretation, but remember this is a useful abstraction, not a necessity nor a reflection of reality. When comparing two people’s hair length, we do not have to remove all their hair and line each strand up straight, tip to tail.
[normal] Measurement and Snap
[normal] As points on a segment slide along a trait, they can snap to other existing points. Like always, this isn’t an infinitely perfect overlap, just an overlap so close we can’t tell which point would be to the left and which to the right. With this we can line up multiple segments to easily measure the full length. It is also easier to imagine merging multiple segments into a single one, as we have been implying with addition. Lastly when stretching elements, it is easy to imagine moving a units endpoint to snap to the endpoint of a second element. All of these operations could be done with measuring, but it is more obvious what is happening with these mental models. This makes further abstraction possible, which leads to further understanding.
[normal] Add and Subtract Lengths
[normal] One can imagine snapping the start and end points to other segment points as you select or slide them. With snapping, a unit selected multiple times (multiple copies) allows adding and subtracting by length rather than just counting. Just take all the units, place them tip to tail, and measure. With the ability to compare units, we can also add segments of different lengths - put them all tip to tail, and measure how many times the unit fits into the total length.
[normal] This tip to tail sorting also deletes any whitespace and overlap information between the segment’s original positions. This is a simplification that we normally do in math, but eventually we will need to understand how to work with these gaps as well.
[normal] Repeated Add and Subtract
[normal] We can repeat selections which allows counting, and we can group selections. This means we can also repeatedly select a group. So 3+3+3+3=12. This is considered multiplication in normal math, but this is NOT multiplication because it is made of multiple selections rather than stretching a single segment. The final number is the same, but this is jumping from value to value rather than moving through all possible intermediate values. In 1D this could be a series of points rather than a line, and in 2D it could be a grid of points rather than an area. We usually write this as 3*4=12, but that confuses it with stretching. In fact it is addition repeated, so in exponent form it is (+3)⁴, where stretching is (*3)⁴.
[normal] Stretch Segments
[normal] Segments can be stretched by moving their endpoints. This allows resizing a segment without needing a new selection. Segments can be resized into precise ratios of a unit. For example, take two unit sized segments, arrange them tip to tail, and then stretch them down to a total length of one unit. Each segment will now be half a unit. They stretched from one unit to half a unit. Also notice the unit itself is now be twice their length. It didn’t stretch at all, but it’s being compared to segments that did. We could have also stretched the unit up to be the size of the two segments. This is a different operation, but our final ratios would not change because all comparisons are relative. All rational numbers (fractions) can be created this way.
[normal] Our normal multiplication is always about stretching, but stretching is not limited to multiplication. It does not even need to involve comparisons or ratios. Imagine a segment that we only know the end point. If we move that end point (and thus stretch the segment) farther along the line, say by three units, it will change size. We still do not know the total length, we just know it is 3 units longer than it was. Of course the ratio of the full segment to the unit has changed, but we aren’t focused on that. This type of move is the same as adding to the end, except for the key fact that is this is a ‘continuous add’. There was motion here, it wasn’t a discrete jump like when you add a segment of three units. A stretch always passes through intermediate points on the way to its destination. Most importantly a stretch always adds or subtracts, continuously, from the total length of a segment.
[normal] Stretch Traits
[normal] Not only can segments be stretched, but the whole trait ‘number line’ itself can be stretched. Stretching a line will also stretch all focal segments that lie on that line. If the unit of measure is included in the stretch, it has the effect of zooming in or out. If it isn’t it makes everything on the line longer or shorter. You can choose to stretch the unit or not, and you can even make a copy of the unit and only stretch one. We’ll call the trait stretching ‘scaling’ just to differentiate it from stretching a segment (moving a segment’s endpoints).
[normal] Scaling traits is key to understanding a lot of what comes next, so make sure you can conceptualize the difference. Stretching a segment is like sliding two beads on a wire, the start and end bead. Scaling a trait is like marking positions on an elastic and then stretching it.
[normal] A scaling trait pivots at zero, so it will grow (or shrink) linearly in each direction from the unit’s zero point. To move the end point of the unit (the one point of the unit) to the 3 position, we need to scale the whole line to be three time longer. This will multiply every segment on that line by three. To move the 3 point to the one point, the line needs to be scaled down by three, and everything on it will shrink by 1/3. Note again that the trait pivots on the zero point of the unit as it’s scaled, so the negative side will stretch in the opposite direction to the positive side.
[normal] The behavior of this scaling is more like a scissor arm pivoting in the center. You can drag the one point to the three point and the whole arm will scale. But it isn’t exactly a scissor arm either. Dragging from the point +1 to the point -1 causes all elements to mirror around the center. This is the same as scaling by a negative number – all segments will end up on the opposite side of zero compared to where they started.
[normal] It is a good exercise to imagine what happens to various points as the line scales. How does this system create fractions or decimals? How does it measure change? What can affect the direction a segment is pointing? What happens with repeated scaling? What happens to our concept of forward as the line is negated? All questions worth thinking about before reading on.
[normal] Repeated Stretches
[normal] Scaling a trait by three time’s its unit will scale everything on the line by three. Doing the same operation again, will scale everything by three again. This is squaring. Doing it one more time is cubing, and so on. This is different than multiplying by 9 or 27 because the operation of squaring is independent of the scaling value. If you go back and change the scale of 3 to a scale of 4, you would still be squaring and cubing — just your end values would be 16 and 64 rather than 9 and 27. In the equation (*n)³, the n is any value, and it will be stretched (*) three times due to the exponent value of 3. An exponent signifies repetition.
[normal] With adding we can ‘teleport’ to any location on a line with a single operation. The same is true for multiplication, where we can stretch for any point to any point. This make intuitive sense, as we should always be able to ‘get there from here’ directly or indirectly. It implies the line is linear, and it is. This is not true for repeated stretches, at least not yet.
[normal] If you square a number, it can’t end up on the negative side of zero. This is true in normal math as well and we are used to it, but it is a bit strange that repeating a stretch makes half of a line inaccessible. It would seem unnatural if we couldn’t stretch a rubber band in the same way twice and not end up in places we could reach by stretching it only once. How does the elastic know about squaring or negative numbers?
[normal] The reality is, we can reach these areas with a squaring operation, just not with common math. These special cases require the fairly baffling “square root of negative one” unit called i. The next sections will try to ‘debaffle’ this problem and show how fits perfectly into things you can do on a 1D line. In fact i represents a very common and very essential concept that has been largely misunderstood — especially in math.
[normal] Measurements and Transformations
[normal] When measuring something, we record the result as a number. We tend to think of numbers as a record of some value. The number 6 represent a count or measure of 6 units of something. Looking at equations however, it’s clear we also use numbers to represent transformations. 3*2 records a length or count of three that doubles, resulting in 6.
[normal] One thing that isn't clear from our current encoding of math, is whether or not a number represents a discrete value or a continuous one. We do know if we are adding or multiplying, but when multiplying it isn't clear if we are stretching or adding repeatedly. So 3*4 has three interpretations. It could be a point at 3 that gets shifted to 12, a segment from 0 to 3 the becomes a segment from 0 to 12, or lastly, it could be 4 people with 3 apples each (3+3+3+3). We know that addition is selection (and therefore discrete) and multiplication is sliding and stretching (and therefore continuous). To communicate the kind of geometry an equation represents, we will need to specify this information in the equation.
[normal] We can specify the geometry of an equation by including the sign for elements as well as operations. For example, +3*4 (note the leading '+') would shift a point at 3 to 12, and *3*4 (note the leading '*') would stretch a 0->3 segment to become 0->12. We also need to distinguish repeated addition from stretching. We know repetition is represented with exponents, but normally we only use exponents for multiplication. Repeated addition can use the same exponents if we specify it is for addition. In this example, +3^+4 would result in four points at 3, 6, 9, and 12. Changing that to *3^+4 would result in four segments. +3^*4 is closer to regular exponents, where the intermediate results are re-multiplied. It would result in four points, at 3, 9, 27, and 81. Of course normal math is all about the result, so it ignores all values but the last one, leaving 3^4=81. Lastly *3^*4 results in four segments, 0->3, 0->9, 0->27, and 0->81. This is quite a bit richer than just '81', and all that extra information can be relevant if you don't throw it away.
[normal] Negative numbers work in much the same way with segments. When stretching by a negative number the segment is flipped around the zero point. The transformations of repeated negative multiplication is much clearer when you see the trail it leaves, as it flips from positive to negative each iteration.
[normal] This is getting closer to a full geometric interpretation of linear values and operations. The only thing left to deal with is the fact that all our segments have been starting at zero. What does it even mean to multiply two segments when they are offset from zero? This is worth thinking about.
[normal] Negative Units
[normal] So far units have always been positive. That is, a unit starts at zero and ends at one. On the traditional number line it points to the right. That is intuitive to us, as all our math is based on positive units. We defined zero as the place the unit starts, maybe we can revisit that, but for now it seems right. We know the length must be one, because it defines one. This allows us to define negative numbers as numbers that starts at zero and point to the left. Or more specifically, they point in ‘the direction of less’, given that left and right are arbitrary here.
[normal] But. But what about having a unit that points in the direction of less rather than the direction of more? It would still start at zero, and its length would still define one. At first this may seem like the same line, and in fact if you would rotate your paper upside down it would be. This is only because we are using left and right rather than more concrete properties that happen on gradients. A number line is best thought of in less arbitrary terms — cold to hot, blue to red, small to large, debt to wealth etc. If we think of the positive unit pointing towards ‘hot’, does that preclude us form having a number line where positive points towards ‘cool’? Is there even a natural direction here? (if there is, due to entropy, it is probably towards cool).
[normal] Lines with hot and cool units are obviously different things. Increasing values on one line make you hotter, while increasing on the other makes you cooler. But does all our math so far still work? Yes, of course, the math agnostic here. However there are clearly two possible interpretations of values. One with a unit that points to ‘hot’ and one with a unit that points to ‘cool’. If we want math to be agnostic to its environment, we need to specify which interpretation we mean when specifying a value.
[normal] This may seem like opening a giant Pandora’s Box where we’ll need to annotate all equations with real world metadata, but it isn’t. All our math so far is with segments, but these segments have mostly started at zero. This is the case in normal math as well, the start point is zero and we mostly ignore everything but the final endpoint. Obviously a segment can appear anywhere on a line. The trick is to define the start point with a negative unit, and the end point with a positive unit. First, let’s solidify what a negative unit is.
[normal] Imagine going to work and coming home on the same route every day. On the way to work, your distance traveled starts at zero, and increases until you arrive. On the way home, you start at work, and your distance increases until you arrive home. This is the same path, but your orientation has changed. There are two ways to think about measurements in this path, one with a ‘from home’ unit we can call positive, and one with a ‘from work’ unit we can call negative (at least in the morning). If you tell someone you’ve driven two miles, there is not enough information there to know if you are getting closer or further from home. In the morning your positive unit will point to work, and at the end of the work day it will point to home.
[normal] Let’s try another, imagine money and debt. For this example more debt will mean poorer and more money will mean richer (this is not financial advice). When talking about debt, the more you have the poorer you are. If you have one dollar of debt, and you multiply that by one you will still have one dollar of debt. Now look at this from the perspective of money, the positive unit. That one dollar of debt sits at -1 on this number line, and the ‘multiply by one’ that happened in the debt perspective appears at ‘multiply by -1’ to the money number line. And the result is -1. So from the money perspective, a negative unit times a negative unit equals minus one. The same thing happens in the other direction, debt sees money multiply a negative dollar by negative one and get minus one dollars of debt. In normal math, this is called the imaginary number, labeled ‘i’, and is usually defined as the square root of -1. As we see here, there is nothing imaginary about it. Normal math treats this as an impossible but very useful result, but it is only impossible when viewed from the single perspective of a positive unit.
[normal] A third analogy, to clarify that there isn’t a correct positive direction to a line, because this is important. It is tempting to thing there are always universal positive directions on a trait, say increasing information or energy vs decreasing. Even time, that only moves in one direction, can use future and past frames of reference. Sometimes we have very singular frames of reference, but it is important to remember this is a choice and not a law. We specify north as ‘the top’, but that is arbitrary in spite of being very common. Faces are upside up, and gravity points down, but they can be interpreted both ways. The English alphabet is left to right, while many others are right to left. Ancient writing often wrote in a snake pattern, where each line alternated between left to right and right to left. There is no ‘universal’ direction in writing, so when we specify the ‘third’ word in a line, we need to know what side the line starts from. In math we label our preferred direction as positive, and the other as negative, but so would people whose alphabets are written in opposite directions. The takeaway is there is no universal direction, but there are always two known ways of looking at it. This isn’t just a preferred way of encoding either — we can flip which side is ‘imaginary’ mid equation, and there are real consequences. And unsurprisingly, the universe does this all the time. Where there is possible, there is actual.
[normal] This all may seem like semantics, but any time you can separate two phenomena, it represents an actual difference. If there are two ways to represent ‘forward’ on a 1D line, reality will not have overlooked one of them. Neither should our math.
[normal] Unit and Unot
[normal] Negative units and positive units are important, but they can create confusing phrases like, ‘positive three on the number line using a negative unit’. For this reason ‘normal’ positive units will be referred to as units, and negative units will be called unots. This is a dumb name, but may be easier to remember because ‘not’ negates a statement.
[normal] Three units is 3 to the right on our normal number line, and three unots is 3 to the left on our normal number line (so the position of -3 on the unit number line). 3 unots is not the same as -3 units in spite of being in the same position. Increasing its value will move it to the left, not the right. In the real world, everything is always moving, so a static snapshot like this can be confusing. -3 units is a car pointing right that reversing at 3 mph. 3 unots is a car pointing left that is driving forward at 3 mph.
[normal] And to reiterate, there is no universal ‘unit’ vs ‘unot’ side - unot just represents the opposite direction of unit, whatever that is defined to be.
[normal] Addition with Negative Units
[normal] Compared to a positive unit, a segment on a line calibrated with a negative unit (a unot) will have everything mirrored (from the perspective of the positive unit). If the end point is to the left of the zero point the value is positive, and if it is to the right, it is negative.
[normal] For the action of addition, new segments are always added or subtracted to the left most point rather than the right most point. Again, left and right is just how we traditionally view number lines - they could be up and down or winding paths. If things get confusing it is always easier to imagine a line that gets bluer at one side are redder at the other. Units will add in the bluer direction, unots in the redder direction. We don’t do this exclusively because we care about the resulting geometric interpretations with straight lines as they represent the simplest form of one dimension.
[normal] Other than the direction, addition in the unot direction is exactly the same as in unit direction. In fact if you rotate the paper you are using upside down you wouldn’t know you are using the unot direction.
[normal] If a positive segment was taken from the unit number line and copied as is to the unot number line, it would then point in the (unit’s) negative direction. Note it isn’t just that the segment is moving to a new position — its sense of forward has also flipped as well. It is like it flips, and it flips the fabric of the line with it. The mechanics of a unot interaction is to flip a number line around its zero point, and then measure with positive to the left instead of our traditional right.
[normal] Stretching by Negative Units
[normal] Stretching a segment on the unot side works as addition does, where scaling by 2 will move the left point until the segment is twice as long, and scaling by -2 will flip the segment over the zero point and stretch until it is twice as long in the other direction. Note however, that this is scaling by 2 ‘normal’ positive units. What does it mean to scale by unots (negative units)?
[normal] As we saw in the introduction to unots, they invert the whole number line. Normally scaling by a negative value will invert the element being scaled, but this is different as it inverts the whole line, but leaves the elements where they are. So scaling by 1 unot just flips the number line around its zero point. Scaling by 2 unot flips the number line and scales its contents to be twice as large. Scaling by -2 unots flips the number line, and then flips its contents while scaling to twice the size.
[normal] So in all scaling there are really two operations, one on the timeline (trait) and one on the contents (focal segments on the trait). We normally don’t notice this as the unit effect on the number line is to ‘scale by 1’ which does nothing.
[normal] As an example, we’ll repeatedly scale 1 (a unit) by unot.
[normal] First run, flip the number line of the 1 segment, which makes it a unot based line. The segment is also flipped by this, so while it still starts at zero and points to the positive direction, the positive direction is left on this line. The two number lines are now synchronized as a unot line, so we can multiply as normal. The two values are 1 and 1, so this creates 1 unot.
[normal] Second run, scale the new ‘1 unot’ by unot. Again this flips the number line, which becomes a normal unit number line again. The endpoint is still +1, now pointing to the right. Again, now that these number lines have been synchronized we can multiply the segments normally. We have a positive 1, and a negative 1 (the location of 1 unot that we are scaling by on the ‘normal’ number line is -1). 1 scaled by -1 is -1 units. Notice how scaling 1 by unot two times (squaring) results in -1. The square root of -1 is unot. Incidentally, with this we can now once again reach any point on a number line by an operation repeated twice.
[normal] Third run, scale -1 by unot. We flip the number line again, creating a -1 unot. The unot we are scaling by has a value of 1 on the unot number line, so 1 scaled by -1 is -1 unot.
[normal] Lastly, multiply -1 unot by unot. This creates a -1 once the number line is flipped, and the unot value on this normal number line is also -1. So -1 scaled by -1 is 1 unit.
[normal] As you may have guessed, the unot number line that uses the mirrored perspective of our normal number line (left is forward rather than right) is where complex numbers come from. The unot part is traditionally called the imaginary part. There will be a lot more to say about this, but for now, complex numbers are a very natural and essential part of math. They are easy to reason about, and are present in all calculations we do whether we ignore them or not.
[normal] A Segment is a Complex Number
[normal] Any mark on a number line implies a length. Even a point implies a length of the smallest resolution, where we can only resolve 'between-ness' but understand the point can't be infinitely small. But this implied point length isn’t just because we aren’t allowing infinity. When we ask how old a person is, we get the answer in years. This is in spite of knowing about months, days, hours, and seconds. We know there is a start of a year, an end of a year, and a duration of at least 365 days -- but we are not focusing on this. We can choose to work at a minimum resolution or we can be forced to by the limits of our technology, but the math is the same. All elements have length, so all elements can be treated as segments.
[normal] Knowing that all elements are segments, it follows that all elements have start and end points (even if their positions are recorded as the same value, or ignored). We could define start and end points with two unit measures, but that implies two points moving in the same direction. We could use a positive and negative number, but that would require all segments to cross zero. A thrid possibility is to use a unit measure for the end point (as we normally do) and a negative unit measure (unot) for the start point. With this we get a segment that is fully defined, and can live in either perspective, unit or unot. This allows all segments on a line to be defined, and we can convert a unit segment to a unot segment by simply relabeling the start and end points. This is a complex number, or better expressed, a fully defined number. A fully defined number can describe any segment on a line, and these segments can be interpreted as increasing or decreasing without adjustment.
[normal] A note on usage for those coming from ‘normal math’, With complex numbers now being fully defined on a one dimensional line, they no longer have the ability to rotate, or do any sort of two dimensional graphing on their own. To graph a traditional complex number like 2+3i, there needs to be a point at 2 in the unit frame of reference (2 units to the right of zero), and a point at 3 in the unot frame of reference (meaning 3 units to the left of zero from the unit perspective). From our traditional number line's perspective it looks like a line from -3 to 2. From the unot perspective it looks like a line from -2 to 3. This is always visually the same segment, it is just interpreted from each perspective. This allows any complex number to be represented as a segment on a single line.
[normal] Normally a point on a line is quantified by its distance from zero, based on a unit size. If we would display this as a segment, it would start at zero and end at the point. This zero point in the new system represents the complex point 0i. A starting point of zero doesn’t affect calculations when we only care about the value of the end point, so we mostly don’t notice that it is even there. We also interchangeably treat this as a segment from zero or point, which is a great source of confusion. Our math works by ignoring the 'imaginary' side if at all possible, however, there are many areas in math (and reality!) where this imaginary side matters a lot. As noted above, every measurement on a line is a segment, even a point. The segment from 0 to 3 is correctly written as 3+0i (which is 0+3i from the unot perspective). A point at 3 is actually a segment from 3 to -3i (which is -3 to 3i in the unot perspective).
[normal] Everything measurable in one dimension is a segment, and every segment is a complex number. As we'll see, all regular math with complex numbers works with this interpretation, and it is geometrically a much more natural interpretation. There are no rotations, and no need to bring in 'e' or trigonometry, no need to map values across graphs etc. Even the 'rotation' that happens when repeatedly multiplying by 'i', from 1, 1i, -1, -1i, has a very obvious cause, and simple geometric result.
[normal] * a segment on a circle with two points can go around either way. With two complex points that isn’t the case.
[normal] * comparing segments include bool ops, union, intersect and subtract.
[normal] A Value can be both a record and an operation
[normal] When seeing a point on a number line at 3 (3, -3i), is usually recorded as the value 3, but it can also be seen as the result of an operation where a point started at zero (0,0i) and moved by one unit three times (or moved by -1 unot three times). A point at 3i would be the same, except it moved by a unot or -1 unit three times. Again, shifting something a number of times is the same as an exponent for addition, so it could be described as something like +[0,0i](+[1,-1i])^3
[normal] A segment from 0 to 7 can be described with a start point and end point, but it can also be the result of an operation that stretches a unit to be 7 times its original length and shrinks to unot to zero. As always, from the unot perspective this would be stretching the unit to zero and the unot to -7 times its original length. All constructs in math have this dual ability to represent either the result of a transformation, and the recipe to achieve it.
[normal] In this sense, we can think of addition as acting on both the start and end points at once, causing a shift. Scaling acts on only one of the points at a time, causing the segment to grow or shrink. Addition is motion, scaling is growth. This type of motion is always continuous and never destructive. This means first, segment end points can never teleport. Second, shifting them or stretching them to zero length does not destroy their integrity, it just makes it immeasurable. Conceptually, a dashed line stretched down to zero length would still be a dashed line.
[normal] That works for continuous things, but certainly there are things in the real world that are not continuous, what of them? Going all the way back to the beginning, non continuous things are always new selections. The difference we see now is that selections are not as simple as we originally thought, because selections always require a definition. In the math sense, we have to define a start and end point, but in the real world we have to define the limits of what qualifies in our selection process. Apples are non continuous, where we can go from 1 to 3 apples without passing through 2, but we have to define what qualifies as an apple before we can select them. A single hair can go from 20 inches to 2 inches when it is cut, but we have to 'unselect' the full hair and select the new section. Yes, this is the same hair, so it may feel that it doesn't need a reselection, but this is only because we define it as connected to the head. The longer piece on the floor is certainly still a hair, but it is unselected, in that we are no longer focusing on it. Ultimately selections require definitions, which requires intelligence. Moving or stretching happens all on its own and is always continuous. It requires comparisons to measure, but these comparisons will always be continuous if inspected. Selecting is always discrete, but requires categorization rules. These rules ultimately will come down to ranges of continuous values, so discrete math must be built on top of continuous math, meaning it is higher level and more abstract.
[normal] Once we establish rules for selection, we can apply mathematical operations that are both discrete and continuous. These operations again represent both the end result and the recipe for the operation. If we 'plant seven seeds that turn into seven flowers', we can see the discrete selection step (seven seeds), the stretch step (growing plants), and even stretching beyond the starting selection rules, requiring reinterpretation (a flower is not a seed). We clearly need to distinguish between elements that can be discrete and elements that can't as they behave differently. Fortunately it isn't hard mathematically, as discrete elements always require a definition, and that definition almost always involved multiple traits (meaning multiple number lines in this sense). In one dimension segments can be discretely selected, and then if they fit the defining rule they are counted. Examples of rules for one dimension could be, e.g. subsegments aren't allowed, points are not considered segments, they have to be within a measurable range etc. This is more obvious in real scenarios, where we talk of the coldest day on record, happiest person in town, or largest pumpkin (where people question if it is still a pumpkin at that point).
[normal] Remember, there are always selections if there are discrete jumps, and selections imply rules. These rules are part of the equation for any recorded value, implicitly or explicitly. By ignoring rules specific to a situation (e.g. how small an apple can be before it is no longer an apple) our math becomes more abstract and useful. It is important to know if an operation is a selection (discrete, rules based) or a motion (continuous on a selection), but more specific rules only become important at higher levels of abstraction.
[normal] Operations on two segments
[normal] So far all operations have been on a single segment, however we've also used two implicit segments for most operations. The first implicit segment was the unit, which is nothing more than a random sized segment that defines the zero point and length one. The second implicit segment was the value we shifted or stretched the segment by. If we have a segment 2 units long, and multiply it by 7, we really are stretching a segment that starts at 0 and ends at 2 by a segment that starts at 0 and ends at 7. The zeros keep everything quiet on the unot side, so we tend not to notice them. First we take the unit and stretch it to 7, and it takes the end point from 2 to 14 as it stretches. Normally when a segment stretches a segment, we need to account for how much each portion of one affects each portion of the other, but when both start at zero that simplifies to 'all of it affects all of it'. This means 2*7 is 14, and there are no adjustments needed.
[normal] To demonstrate how segments aren't normally so well behaved, imagine the 0 to 2 segment being 2 to 4. Same length, but now what does it mean to stretch it by the segment 0 to 7? This isn't too bad, as the new segment will be affected by the whole 0 to 7 segment. You can imagine all parts of that segment stretching 7 times, resulting in a segment from 14 to 28 aka (-14i,28). What about if the 7 was a point though? Now all of the start and end points affect each other, stretching each other proportionately to their values, and we end up with a larger segment pointing in the opposite direction, from 42 to 14 (-42i, 14). This may seem confusing, but it isn't too hard to get an intuition for multiplying segments if you remember every part must affect every opposing part. Because segments are linear and continuous, we can reduce this to both endpoints of the course affecting both endpoints of the target. More on multiplying segments later.
[normal] Comparisons are measures of similarity. To compare directed segments (complex numbers), we should first attempt an exhaustive list of the ways segments can be compared. The restriction at this point is both segments have to be on the same line. They can point in the positive and negative directions, they don't have to start at zero, and they can use either unit or unot perspective. We will start with the simplest segments
[normal] There are three ways of comparing two values: compare A to B, compare B to A, or compare A and B to a third value C. The first two define the unit using only A or B, while the third allows an external unit C. However, as discussed elsewhere, there are no universal external units. This means C is actually a third value here, and so not a valid way of comparing two values. When not using an external unit (so only using A and B), there are still a number of variations that can be used for a comparison.
[normal] At the most basic, values can be compared additively or by scaling. Scaling answers ‘which is larger’, while additive shows ‘how much extra’. In these examples we can imagine lines on a page where we are comparing length, however as always these types of comparisons will apply to any measurable values.
[normal] Additive comparisons are of the form A-B or B-A, where one element becomes the unit (so 1-X or X-1). The result is the ‘extra’ (or the not enough). To measure this extra value would still require scaling, but even without measurement, the result is the absolute difference between the two values. Repeated subtractions of the smaller unit could give a rough count, but scaling can also answer count.
[normal] Estimating fractions can be done additively using only discrete values, by always taking remainders less than the unit and making them the unit. As an example, if you have a length 2.5 times larger than another, the smaller one goes into the larger 2 times with a remainder. This remainder goes into the original unit 2 times, meaning it was 0.5 times the size of the original. Adding these together gives us 2.5. We can get this result a little more naturally with scaling however, as scaling is continuous to the limit of our precision. Scaling the smaller unit into the larger one requires us to stretch it 2.5 times its original size. While scaling may be a more natural way of measuring value comparisons, there are entire branches of important mathematics that use discrete techniques. As always, every fork in the path is valid and leads to valuable insights.
[normal] While scaling comparisons are computationally simpler, they still allow many potential ways of comparing two values. As with additive comparisons, there must always be a unit. The possible comparisons are A/B, B/A, and then iterations with a composite unit like A/(A+B), or even B/(A*B).
[normal] We can also control our ‘selection of unit’ step, using a heuristic rather than A or B. For example, the heuristic ‘Select the longest line for the unit’ results in a value normalized between 0 and 1. This normalized value expresses how similar A and B are, with 1 being the same and 0 being not at all the same. ‘Select the shortest line for the unit’ would also compare similarity, though the result would always be greater than or equal to 1, and larger would mean less similar.
[normal] If we expand this to allow for negative lengths (imagine directed lengths on a number line rather than lines on a page), then we need to define what we mean by ‘longest’ when selecting the unit. If longest means ‘visually the longest’ (the absolute length), then comparisons result in a value between -1 and 1, with 1 being the most similar, 0 being the most unrelated, and -1 being the most mirrored. If ‘longest’ means ‘the most positive’ (greatest value), then if either line has a positive length, the comparison results in a value of 1 or less, and two negative lengths create a value of 1i or greater. The ‘most negative’ version would be similar, but any negative number creates a value greater than 0i, and two positives will be 1 or greater. All of these could be done using the ‘shortest’ unit rather than longest, resulting in opposite permutations. This all gets a bit complex, and starts to feel like we are inventing rules rather than discovering them. It also seems a bit unnatural that comparisons between two lines have forbidden values. The only heuristic here that allows a result that could potentially fall anywhere on the number line is a random selection of the unit. This is resolved in the next section when comparing segments.
[normal] Another option for comparing two values by scale is to synthesize the unit, for example making it the sum of A and B. Technically this unit is a third value, but because it is created from the first two should be at least considered. The (A+B) unit results in A/(A+B) and B/(A+B), each being a proportion from 0 to 1 (assuming only positive lengths). Allowing for both positive and negative values for A and B, the unit construction has a few options. If is the total absolute length (|A|+|B|), the resulting ratios would represent the amount of positive vs the amount of negative. If two values are positive in this scenario, the positive ratio would be 1, and the difference between the two positive numbers would be lost. Alternately, a system going from -1 to 1 could be used here, though this would require supplementary rules to define edge cases.
[normal] This is an example of how simple comparisons can break down using just our traditional real numbers. More and more ‘user defined’ rules are required, and the system becomes dependent on tradition as much as reasoning. And it isn’t just with comparisons. Imagine a segment that starts at 3 and ends at 5. Multiplying this by 2 would result in a 6 to 10 segment. But what would it mean to do the reverse, multiply those segments by each other? Or multiply them by a segment going the other direction, or existing on the imaginary side of the number line?
[normal] This complexity isn’t due to nature, it is simply because we are used to ignoring the imaginary parts of numbers. We do this because they are often (but not always!) zero. When the imaginary parts of a full number contain valid information that is discarded, we define a somewhat arbitrary set of rules on what to discard and how to preserve the rest, based on our needs of the moment. This more or less works, but a much better (and existing) solution is to just use complex numbers to preserve everything. Arbitrary heuristics have their place, but their price is usually steep: added complexity, destroyed information, and obfuscation of what is really happening.
[normal] Note: In all of this, we haven’t compared using zero. This isn’t avoidance. If an additive measure isn’t defined, then there aren’t two things to compare. If a scalable measure is zero, we know it isn’t actually zero, just beyond our resolution. In this case x/0 would simply be higher than our maximum resolution.
[normal] Segments as complex numbers
[normal] Complex numbers consist of a start point (the imaginary part) and an endpoint (the ‘real’ part), making a segment. Each of these points can also be thought of as separate segments starting from zero, which equates to the 2+3i type of complex encoding we are used to. We often think of ‘real’ numbers as a point on the numberline, but it is better to think of them as a segment that starts at zero and ends at the number. In this case the number would either be a complex number with a 0i imaginary part, or the endpoint of a segment with the start point defined elsewhere. Either way, when comparing two segments (complex numbers) there are four positions we need to look at, the two points of the first term (A and Ai), and the two points of the second (B and Bi). Using all four points allows all types of comparisons between all types of segments a valid operation. Not only can one segment transform into another through addition or multiplication, things like the square root of a segment can be calculated without worrying about NaN’s or infinities (in computer parlance).
[normal] These complex number segments are directed, meaning they have a start point and end point, and point towards the end point. For now we say the imaginary part is the start point, and the real part is the end point. This fits our current number system, where we mostly ignore an imaginary part with zero value, and just take the end point as the value. But remember, there is no universal preference for which side should be labeled imaginary. If you rotate the whole trait, the previously imaginary part will point to the right, and it behaves exactly as the former real part did. There is no measurable difference between these, other than they define ‘forward’ in opposite ways. This makes for two main operations, mirroring and rotating. Mirroring is negating a value, where 3-2i becomes -3+2i. Rotating is making the imaginary part real, and the real part imaginary, exactly as if you rotated the trait itself (though this isn’t a requirement of course, you are just changing the orientation). This pattern of rotation and negation is key for all math to come, so it is good to understand it well. Rotation and negation aren’t fundamental due to some magic cosmic dictate. They are fundamental because there are only four possible changes that can happen to a measurable value - move ‘forward’ and increase, move ‘backwards’ and decrease, and then from the rotated perspective, move forward and decrease, move backwards and increase.
[normal] Manipulating Segments
[normal] To compare two segments, all four endpoints are required (A start, A end, B start, B end). If just comparing the lengths, we need to ignore any gaps or shifts of these lengths along the numberline, meaning the segment must be shifted until the start point is zero. This shouldn’t be confused with ignoring the start point though! We need to shift it so the result isn’t affected by it, not ignore it.
[normal] These four points result in many choices in how elements are compared, some of them more intuitive (though not ‘more valid’) than others. It is always helpful to try and ground these operations in a concrete example. When comparing your work-to-home route to your home-to-work route there are a lot of symmetries, especially if it is just the same route backwards. But what about comparing two separate sections of each? Would the ‘total’ distance of the two be an addition or a subtraction? How would one scale into the other? One can imagine sliding start to start and end to end, but what does the encoding of that operation look like? Two segments are certainly comparable, but there are many ways to go about it. Existing addition and scaling process definitions can be extended to define processes for comparing two segments.
[normal] Adding Segments
[normal] Segment addition is intuitive - just add the start points to get the final start point, and add the end points to get the final end point. This is how complex addition works as well. Subtraction of course works the same, other than subtracting like points rather than adding them. Notice this is different than what the conversational concept of adding segments might be, where the lengths are added up. This would be placing all segments tip to tail starting from zero, and recording the final endpoint as the total length. This is also a valid operation of course, but is not adding segments in a complex number sense.
[normal] Multiplying Segments
[normal] Scaling segments by segments isn’t immediately intuitive, but when they are ‘zero anchored’ things are familiar. These are segments like 7+0i, -6+0i, 0+5i, or 0+-4i where they will just proportionally stretch a segment along the number line. For example we can see a segment that starts with the range 2->4 (-2i+4) and ends with 6->12 (-6i+12) has been scaled by three. The initial gap scales pretty naturally, and even if being scaled by 3i instead of 3, we can pretty easily see the timeline flip and then the normal scaling.
[normal] Things get less intuitive when we scale by a complex number that isn’t zero anchored, as we now have to account for the ‘gap from zero’ in both elements. Imagining this using regular numbers, it is like changing the stretch amount from 0->3 to 5->8. What does it mean to stretch a segment by a certain amount that includes an initial gap like this? Should the resulting length still be the same, or is it some balance of push and pull? Clearly the offset start point should affect the result somehow, otherwise stretching by 0->3 wouldn’t be any different than stretching by 5->8.
[normal] To answer this we need to consider all the positions that are affecting the stretch. The ‘force’ of a stretch comes from all the different sections of the range causing the stretch, and the result will be a new continuous range will be made of sections that can map back to the original ones. Because these new segments will remain in order, we can reduce this whole operation to stretches on the end points, and then infill the result with interpolation. As every section of the start segment (A) will pull or push every section of the end segment (B), we can reduce this to the sum of ‘how much start point A affects segment B’, and ‘how much endpoint A affects segment B’.
[normal] This is exactly complex multiplication.
[normal] (A+Ai)*(B+Bi) = ((A*B)-(Ai*Bi)) + ((A*Bi)+(Ai*B))
[normal] This looks complicated, and we can simplify it, but the important thing is to see what it is doing. On the left side, it scales the two endpoints together, and then the two start points. The start points need to be subtracted from the end points, because they represent the ‘gap’ range that was removed from the segment zero anchored endpoints would have made. We can’t just leave it at this however, otherwise we would get the same results no matter how large the gap was. So the right half is adjusting for how much the start points push and pull this resulting segment. The result of both of these added together account for all the forces on the start and end points of the original segment, and comes out as a new complex number. There are stretches on both the real and imaginary sides here, and in two cases the timelines are flipped as well (Ai*Bi) and (A*Bi). The results aren’t always intuitive, but if you think of at forces it is at least easier to understand what is going on. And this is a very normal way for things to behave in the real world, so it is worth building an intuition.
[normal] Note that in normal math, complex numbers are placed on a 2D grid (with i being the vertical axis), and then trigonomically converted to polar coordinates of lengths and angles. Math is done in this coordinate space and then converted back to points. There gives a sense that complex numbers are two dimensional, and multiplying them somehow causes rotation. As you can see, complex numbers are one dimensional, and have nothing to do with rotation. In fact all it really says is Cartesian coordinates can be converted back and forth with polar coordinates, which has nothing to do with one dimensional complex numbers.
[normal] Comparing Segments
[normal] As with values, segments can be compared using the absolute difference (subtraction), or the scaled difference (division). Subtraction is quite intuitive, making it easy to see how the remainder segment represents the difference of the two segments being compared. Division is a complex formula and not always an intuitive result, but is one of the more accurate representations of how ranges of values compare in the real world. That said, the four end points on two segments does mean there are other valid ways of comparing, beyond subtraction and division.
[normal] A common way of comparing two segments in traditional math is the dot product. Its meaning is fairly nuanced, but this idea is you draw lines from the origin to two points, and then by (X1*X2)+(Y1*Y2) you get a single real number value you can interpret. Looking at that equation, you can see it’s kind of showing how similar the real sides are, and joining that with how similar the imaginary sides are. In 2D these values represent (something like) how much one line would affect the other if it was scaled along its direction. If the lines are perpendicular there would be no effect, so the result of the equation is zero. A negative value would mean the lines are pointing away from each other (scaling affects the other, but in the opposite direction), and positive would mean they point more in the same direction. These results can also be obtained with |a|*|b|*cos(angle) if you convert everything to polar coordinates, though that is probably true for any types of values you convert to polar coordinates. This equation normally reduces two segments to a scalar, so it does lose most of the original information, and most of the potential information from the comparison itself. The destruction comes mostly from the addition of the X and Y results, as they combine two elements into one, losing any information about the ratio between them.
[normal] When looking at (X1*X2)+(Y1*Y2) in the context of complex number segments, the equation separates the real (A) and imaginary (B) components of the segment, and keeps them separate in the result (C). Two segments compared result in a segment rather than a scalar as you don’t naturally add the real and imaginary parts together (Ai*Bi)+(A*B)=(Ci+C). Of course you can still add or otherwise manipulate the real and imaginary parts if you wish, to find length as a scalar for example. Doing this with complex number segments works like a dot product in that it compares similarity of the segments around the origin (zero). If both values of C are the same the two segments are identical scales of each other, if they add to 0 they are mirrors.
[normal] Repeating Scaling of Segments
[normal] The repeated scaling of a segment is the same as raising it to a power - repeating twice is squaring, three times is cubing, etc. The mechanics of this is just stretching the segment to be n times its length a fixed number of times. Note that it is always the total length of the last results that is stretched, not the same initial amount. +(*3) repeated three times results in three dashes, whereas *(*3) repeated three times is cubing.
[normal] The repeated element getting stretched does not have to be constant. It can be derived from the result as with Euler’s number, it can be a series, or it can be arbitrary. Arbitrary becomes regular multiplication, which is very useful, but loses the special properties the constraints of powers bring. The number of times something is repeated can also change in each step. This is common with polynomials, in the form of 8x4-4x3+3x2−7x+1=27. The segment version of this would be the unit x being stretched repeatedly in steps, where the next polynomial always appends a new unit to the last result before stretching. The result is multiple directed segments all tip to tail, and the final tip would be the location of the final endpoint. The whole thing can be then scaled so the final position matches the desired result (27 in this case).
[normal] Due to a squared number having more than one solution (-22 and 22 are both 4) polynomials can quickly become very intricate, and even more so when dealing with full complex number segments. Many of the great discoveries in math, including complex numbers themselves, were based on trying to better understand polynomials. However, if a rule is imposed where the unit is always 10, and neither negative or imaginary numbers are allowed, you will get the positive rational numbers (3*102−7*101+4*100 is what we mean when we write 374). It may seem strange that one of the simplest things in mathematics becomes one of the most puzzling by just allowing negative numbers, but when you consider how these flip segments around the zero point, you can see how imaginary numbers (which flip the number line itself) are required to ensure any point can reach any point on a number line. All of these transforms lead to multiple solutions, which are all valid observable results in the real world, but also much more complex than simple positive scaling and appending.
[normal] Squaring is Repeating
[normal] What we know as squaring is a subset of the repeat operation, specifically repeating a stretch two times. Cubing is repeating a stretch three times. What else can be repeated? A shift (addition) can be repeated, so +34 is actually 3+3+3+3 (we normally see *34 as 3*3*3*3). This explains why we don’t differentiate between 3*4 being a continuous length of 12, 12 objects, a grid of 3x4 objects and an area of 3x4 square units. Stretching and shifting are different operations, but we don’t always distinguish them.
[normal] The other interesting thing about repeating is that we don’t have to limit repeats to just using the positive unit. We can repeat a negative stretch (-3*-3*-3*-3) causing the result to flip between positive and negative. We can also repeat with a negative unit, causing the cycling of 1, i, -1, -i. These are mirroring values and mirroring the number line. So while standard positive repetition creates a symmetry (ab ab), the addition of the two types of mirroring (ab ba, ɐq qɐ, and qɐ qɐ) allows the creation of all possible symmetries along a 1D line. Symmetry is the basis of much of modern math. It’s the only current system that can express all underlying patterns that are possible with repeated stretching and shifting of values.
[normal] What do complex numbers represent?
[normal] In general complex numbers are the balanced form of a number that is made of two opposing properties. This is different from positive and negative, as those measure the values that agree on what direction is ‘forward’. This may seem a minor distinction, but only because we are used to dealing with numbers that zero out the imaginary side (segments that start at zero). In fact, all measures are complex numbers of some form, because all measures are segments.
[normal] In electronics many values are already expressed with complex numbers, such as voltage/current, or the phase of an AC signal. In physics complex numbers are an essential part of the wave function, and used to represent various spins of particles. At higher scales, they allow the potential and kinetic energy of a system to be expressed as.a single value.
[normal] Credit and debt is often thought of in terms of positive and negative numbers, but in double entry accounting there are two accounts (credit and debit) and they always balance. Each account records the same thing, but has a different perspective as to what positive means. Another example would be exchanging money. If one bank gives 100:1 with no commission that would be a segment from 0 to 100. If another bank gives a rate of 105:1 but has a 5% commission, that would be a segment of 5 to 105. As you stretch these segments by whatever amount you wish to exchange, the return will be the same (the length of the segment), and the commission will be recorded by the start point.
[normal] There are many more examples of complex number use in math and science. Quantum spin, where a particle moves to one of two states when measured, is described with complex numbers. It has been shown in quantum mechanics that complex numbers are not just a convenient formalism, but a requirement. More generally, we see the pattern of two possible orientations along a gradient in more organic areas. In language we have ‘direction’ to ideas, like fast and slow, or good and bad. Applying very or not to these words amplifies or negates the direction, but keeps the ‘frame’ of the direction the same. Quadruples like fair-unfair-unbiased-biased, or combed-uncombed-tangled-untangled show the differences between a negation of a value, and a flipping of the context (number line) that happens when multiplying by i.
[normal] Ultimately, complex numbers represent all measurable values as they appear in the universe - aka numbers. Our current numbers represent part of a number, and we do most of our math with partial numbers.
[normal] Objects
[normal] Discrete ‘countable’ objects are always based on a definition, where traits are based on values. These definitions are made of probable ranges (focal segments) on specific traits. There can be many traits involved, and there can be multiple values on a single trait combined in specific ways. For example a zebra is black and white, whereas sheep can be black or white.
[normal] Trait positions always have an intrinsic value based on differences, even if there is no number or unit assigned to them. Abstractly, this is because there is a natural gradient of entropy in the universe, but in a more down to earth way, traits are properties that can be measured, and it isn’t possible to measure properties that don’t change.
[normal] The simplest example of things that can be counted are the counting numbers themselves. The definition of a number can be geometric, such as all numbers being represented by segments of equal length. It could also be defined in terms of discrete events, discrete objects, discrete locations etc. It is important to note that the definition of what we count doesn’t require a method of ordering. When seeing a bowl of oranges on the table we can count them, but there is no set order to them. There are also no fixed sizes, only probably ranges. Six oranges gives hints about the total weight, but there isn’t a simple multiplication by six that would be anything but approximate.
[normal] Much of math involves discrete objects, so it is important to understand exactly what this means. With traits and segment measures there is no ‘zero’, only values smaller than our ability to measure. With discrete objects there can be zero, as in you can not select an orange. This doesn’t imply that there can be infinity with discrete objects like it would with traits, as you can’t
[normal] stretch discrete objects. Stretching a zero would require infinite scaling to fit into a unit. With objects our only options are partitioning and adding (you can have half an apple with a cut, but even one apple twice the width of another apple isn’t considered to be two apples).
[normal] As mentioned, discrete objects have no set order, so the order must also come from a definition. This can be as simple as sorting by a trait in the definition, such as sorting apples by size, color, or sweetness. The order can also be something more complex algorithm based on multiple traits, or external events. They can also have multiple valid orders, or no order at all. How a set of discrete objects are ordered is important for many branches of math, as wide ranging as probability to calculus, to group theory.
[normal] Factorials
[normal] Factorials are written as 7!, which means 1x2x3x4x5x6x7. While they have many uses in math, a key idea they represent is the default scaling of complexity in a system as countable elements are added to it. This often implies order, but does not require it. For example if you give five people an apple each, there are 5! (120) ways those apples could be distributed. The order doesn’t matter, but those 120 permutations still exist. This is the default case, with no extra apples or people, and no conditions. There are ways to move this scaling into continuous values, but the concept remains the same.
[normal] This is probably the most universal ‘constant’ for scaling patterns, and is used as the ‘measuring stick’ for many dynamic systems that update themselves. Each update adds a default amount of complexity. The system must not only account for this, but also can use it to measure and direct itself. Factorials are used in probability and calculus, as well as in sequences of all sorts, such as calculating sine, cosine values, and Euler’s number.
[normal] The other thing to note about factorials is they get very big very fast - much faster than exponents for example. The complexity of the universe unfolding step by step ensures that even the strongest signals eventually get overwhelmed, fading over time, distance and noise. Math exploits this, allowing us to approximate some values to incredible precision - as the complexity of iteration increases, the relevance of each step decreases.
[normal] Grouping
[normal] Once multiple segments are selected or generated, they can be compared and categorized. Just as there are many orders that can be defined for a set of segments (order created, length, starting position…), there are also many groups. Grouping is a simpler operation than ordering, as it doesn’t require a definition to differentiate all elements in the set. In fact it isn’t even necessary to be able to distinguish individual elements. For example dividing segments by positive and negative pointing directions doesn’t require all segments to be unique, just their two possible pointing directions.
[normal] This is true with objects as well. The groups can be chosen from multiple traits, or even by whether or not they contain a trait. It is easy to see that while groups and objects are clearly discrete, there can always be ambiguity around the categorizations. A bucket for green apples and another for red can encounter apples that partially conform to both groups (a green apple starting to turn red), or nether (a yellow apple).
[normal] Groups are naturally discrete, however they can be defined for continuous properties, and they can be continuous themselves. For example, group assignment can be based on a probability of belonging to a category rather than a discrete yes or no.
[normal] Nesting
[normal] Groups can also contain groups. This is something we are used to in the real world, and it is also commonplace in math. When we say 3x4 (in the repeated addition sense, 4+4+4), we are creating a group of three things, that each contain a group of four things. This results in two levels of nesting: ((1111)+(1111)+(1111)).
[normal] This isn’t the case with stretching multiplication - exponents are the result of groups of groups with this operator. If we stretch a value by its value twice, say 3*3, this is squaring. If we do it three times (3*3*3) this is cubing. This is grouping a ‘stretch by value’ operation three times in a row, nested three deep. This results in three levels of nesting: (3*(3*(3))).
[normal] Nesting does not have to be uniform. Symmetry, polygons and groups (in the Group Theory sense) can be expressed in terms of nesting. For example we can see symmetries in nestings like ((1,2,3)(3,2,1)), and perhaps see a rectangle in the nesting ((1,2)(1,2)). We will cover this in more detail later, but keep in mind that nesting can be a great tool for inspection and comparison, as well as categorization.
[normal] Nesting and grouping of segments within a trait can use any of the operations that exist in trait math. This means they can contain gaps, they can reference previously computed values, and they can iterate on previously derived values, or even values from separate traits. Doing all this is usually straightforward, however understanding what it implies isn’t always obvious - in spite of always being valuable.
[normal] Feedback
[normal] Grouping and nesting are ways of separating elements or actions into levels, but as alluded to, these levels can reference elements from previous levels. An expression with multiple levels describes operations that take place in steps. Each of these steps follow the normal expression pattern of ‘inspect, select, predict, simulate and evaluate’. As the steps are now separated we can see the loop is made of ordered steps, and these steps have access to the input and results of previous steps. A classic example of a feedback equation is the Fibonacci sequence, 1,1,2,3,5,8,13… where the next result is always the sum of the previous two results. One can imagine many ways of encoding this type of behavior with specific select and repeat operations.
[normal] It isn’t just algorithms that are based on feedback, in fact many important constants are derived with such feedback sequences. We are used to having pi, e, sine and cosine values just being available, but they ultimately have been calculated with a feedback mechanism. Euler’s number could be calculated by dividing a unit into N equal pieces and adding one of those to a unit (making say 1.01). When this total is repeatedly stretched by it’s result N times (so *1.01, then *1.201, then *1.030301… N times) you end up with approximately the ever useful Euler’s number: 2.71828… Notice how we not only needed to remember the previous result for the next operation, but we also needed to remember N.
[normal] Feedback allows some elements and operations to remain constant over time, some to vary, and some to change behavior. The symmetry of things come from what holds, and the variation comes from changing values and contexts. Looking at it this way, perhaps it isn’t surprising that so much of the world needs feedback for math to properly describe it.
[normal] Rate of Motion
[normal] A full number has a value and a transform, and is agnostic to the element it transforms. The default ‘input’ element for addition is 0, and the default input for scaling it is the unit. Because this input can be any element, the full value also represents a description of the transformation it causes. If a full number represents the record of a value and the transformation it causes, it makes sense that it also characterized the transformation. This is done by quantifying how a change in input changes the output, the ‘rate of change’. This is the basis of calculus, specifically it is the derivative.
[normal] First, if you just have a full number where the input is 0 (addition) or unit (scaling), then the result will always be the same, so the change is 0. The derivative of a constant is 0.
[normal] Addition of a full value will always offset an element, but only by the offset of its value. So +2 will never be more or less that +2 units away from the input. This can be thought of as 1:1 with the input, or 1 scaled by the net change. This means the derivative of addition is always 1.
[normal] Scaling by a full number will change the input to be scaled proportionally by its value. A full value of *3 will always change the input to be 3 times its original value relative to the unit. The stretch is always directly proportional to the value of the full number, so the derivative of a scaling is always the scaling amount.
[normal] Repeated scaling will grow input at an accelerating rate. If you scale something twice, it will change by the scaling rate twice. Scaling by the same amount five times will change it at five times the scaling rate. (*3x5) will change any input to be scaled by 15, and (*SCALExREPEAT) will change the input to be whatever the scale is, multiplied by the number of times it repeats. The derivative of repeated(r) scaling(s), also known as an exponent, is s*r.
[normal] These are the simplest derivatives, however things go much deeper of course. For example, a derivative of a repeated scaling can just be declared to be equal to itself (meaning it is changing by 3 times if it is 3, by 8 times if it is 8). This ends up being true when Euler’s number(e) is raised to any power. Another interesting one is when the derivative is the reciprocal of itself, which as we’ll see results in sine and cosine.
[normal] The most important thing to understand with all these rates of change, is that one dimension (a line) can fully represent all as pest of a full number, but only if the extra dimensions are encoded as time. If only taking a frozen snapshot, *2 repeated three times is indistinguishable from *6. When allowing for the time component (repeats), we can compress any number of dimensions into one, but essentially need animation (repeated frames) to visualize it.
[normal] The full representation of a value includes the operator, and this records a value, describes a transformation, and is an action that can be applied to transform an input. An adjective/noun, an adverb/verb, and an event. All in one.
