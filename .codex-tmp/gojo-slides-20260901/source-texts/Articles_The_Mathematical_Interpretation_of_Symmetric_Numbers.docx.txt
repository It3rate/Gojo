[Heading 1] The Mathematical Interpretation
[normal] As explored in the last article, “Boolean Arithmetic with Segments”, boolean values can be considered weighted values that have some true/false threshold. So when we see the four boolean units here, identity, negative-progress, negative-goal, and inversion, we should consider what the weighted version of these mean. They are at the heart of mathematical transformations, and core to defining numbers themselves.
[normal] Our numbers are defined by the unit segment that defines 0 to 1, and a second segment that starts at 0 and extends to some non fixed length. The number is computed by comparing the unit length to the segment in question.
[normal] For a ‘positive to the right’ numbering system like ours, the unit needs to start at zero, and move to the right. From the zero perspective, the goal position is one unit away. From the goal position, the start is -1 away. This suggests that the unit value is on the line with the opposite polarity. From our normal perspective it is position 1, and indeed from its own perspective it is also 1. All unit values are 1, it’s just the units themselves come in four flavors. The red unit’s location is ‘the negative side of the line that is positive-left’, so the unit is -i. This is confusing because of overloading the - operator here, imagine we have units of miles, and other units of ‘negative miles’. Really it is more like “1 negative inverted unit”, or <insert better name here>. It is the going-backwards-while-facing-left unit :).
[normal] When used to measure the green line, it can be converted by position into the green unit, and its position is 1.
[normal] There are reasons to prefer using -i as the unit of our normal numbers, rather than 1. It takes two segments to measure something, a unit and a length to measure. If they both use the same unit and are the same length, they are mathematically identical objects. Which is dividing by which in that case?
[normal] The only way to differentiate the two is to have them on different line polarities. It makes sense that a positive value moves towards the unit, and the unit is the landmark that positive things move towards. These are opposite perspectives, the unit starts at position 1 and goes to 0, the value starts at 0 and goes in whatever direction it encodes.
[normal] This final value is the only one that is variable (the 0, 0, and 1 are constants), so we can encode a number with one value. That value is the ‘goal’ or the ‘end point’.
[Heading 1] Segment Numbers
[normal] What about the numbers in the opposite polarity? This is the same system with everything negated. These will have their unit on the left side, from the -1 position, to zero. Of course this can be treated exactly as our own numbers, just flipped horizontally and vertically (akin to moving to the other side of the table). When combined together though, the inverted version will indicate the opposite values of the normal one. The meaning will be the opposite as well, measuring the distance from the start, rather than the goal. The progress so far rather than the final value. The starting position rather than the end.
[normal] So for segments not anchored to zero, the start position moves in the opposite direction as the end position. This makes sense, because a segment from 3 to 5 has a length of 2, not 8 (-3+5=2 vs 3+5=8). That implies the start point has had a head start, a distance that is skipped or subtracted. Putting the start point in the opposite perspective of the end point allows this. For example, below is a segment that starts at 2i in the inverted perspective, and ends at 4 in the normal perspective. Notice how these units map to the four symmetric transformations.
[normal] This segment number system actually only relaxes one extra constraint compared to normal numbers. The two units are a fixed value of 1, and are both the same length. The start point and the end point are variable. This is why it only takes two values to express a segment (aka a complex number) – the two unit values are a constant value of 1, and always the same length.
[Heading 1] Beyond Segments
[normal] What about relaxing a third constraint? At first this seems like it would be chaos, as the two units would not need to be identical. That points to where it would be useful though, environments without units.
[normal] Imagine a primitive life form has two light sensor eyes, one on each side. There is no universal lumens reference in this world, and each eye is imperfect. The darkest and lightest points of each aren’t always going to be the same, damaged or otherwise, so there isn’t even a common minimum or maximum for each eye. Perhaps even the resolution isn’t constant, one could see in ten steps of brightness, the other twenty. The constant here is they both belong to the same organism, so they will experience the same stimulus, unless there are local reasons for a difference. The organism needs to utilize this messy low resolution information to help maintain its balance of energy and internal conditions.
[normal] The first requirement is to have some reference point. Day and night are very different, so there isn’t an external constant. By keeping an average as it moves and spins around, it could get an average input over a certain period of time and use that as a ‘zero’ reference. Then each eye would move above or below that zero point as it swims through its environment. It needs to dynamically calibrate its sensors, meaning the reference point and the unit size both need to be flexible.
[normal] This creates a positive or negative segment value in each eye. Both segments are zero referenced, so there is no unit. The only option is to set one as the unit and compare it to the other. This allows calculating which is greater, as well as knowing if the total light is increasing or decreasing. The averaged zero point also gives an indication of how much ambient light is present. This system is something like our numbers, with the main difference being that both the zero and one positions of the unit are ‘floating’ over time, and the choice of which value should be used as the unit is arbitrary.
[normal] We get a truly floating system with a second sampling. Now there are two directed segments with a slowly floating zero point. All four positions of the two segments are floating, so while any area can be used as a unit, there can’t be a constant unit. There is a surprising amount of useful math that can be done with these floating quadrants!
[normal] We’ll go over this math in the next article, but suffice to say there is a lot of utility that emerges from the selections, comparisons and transformations of these areas. With the addition of resolution and the above symmetry actions, a basic pseudo organism becomes viable. With a minimal node count, a trainable prediction engine can steer through its environment and sustain itself.
